## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| 以舊雜湊證明未變 | antigravity 把遷移前 sha256 當作現況證據 | blocking | 驗收腳本即時量測並與「執行前當下記錄」比對 |
| 空結果誤判為通過 | 我的隱私測試腳本寫錯，查詢沒執行卻印出「0 筆外洩」 | blocking | 隱私/洩漏測試必須先證明目標資料確實存在（有查詢紀錄、表有列）再判 0 |
| 用計畫自己的例句驗證計畫 | 紅旗詞表只用計畫內正例會測不出盲點 | advisory | 驗證時自己另想句子（Phase 8 因此抓到「吃了整瓶糖漿」漏報） |
| 工具輸出被壓縮 | RTK 會截斷 curl 長輸出，導致 JSON 解析失敗（假象） | advisory | 用 python urllib 或存檔後解析 |
