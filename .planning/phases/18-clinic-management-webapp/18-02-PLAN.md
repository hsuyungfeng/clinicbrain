# Plan 18-02: 直覺視覺化 Web App 前端介面（單頁管理系統）

## 1. 目標
在 `src/web/static/` 建立現代、自包含、輕量直覺的單頁應用（SPA），由 FastAPI 直接掛載。具備診所專屬儀表板、待審衛教草稿視覺化卡片（展示 SOAP 溯源、一鍵核准/駁回）、文件拖曳上傳與結構化病歷檢視。

## 2. 實作任務（指派 Agy 3.6 Flash）
1. 建立靜態資源目錄與單頁應用:
   - `src/web/static/index.html`（HTML5 結構）
   - `src/web/static/app.js`（前端互動邏輯）
   - `src/web/static/style.css`（現代化響應式排版，可引入 Tailwind CDN）
2. 頁面功能規劃（四大切換頁籤）:
   - 🔑 **API Key 認證模態視窗**：首次開啟提示輸入 `CLINICBRAIN_ADMIN_API_KEY`，儲存於 `sessionStorage`，自動附加至所有 API 請求。
   - 📊 **儀表板 (Dashboard)**：呈現待簽核草稿總數、診所病歷總數、快取狀態指標。
   - 📝 **待審草稿簽核 (Review Dashboard)**：
     - 卡片式呈現 pending 草稿。
     - 顯示標籤：SOAP 提煉 vs LLM 生成 vs 診所上傳；類別（special / general）。
     - 若為 SOAP 提煉，展開顯示病歷溯源細節（參考病歷數、居家照護特徵）。
     - 提供「✅ 核准發布」與「❌ 駁回」按鈕，操作後即時更新狀態與卡片移除。
   - 📁 **文件上傳中心 (Upload Center)**：
     - 支援拖曳上傳 `.docx`, `.xlsx`, `.pdf`。
     - 診所代碼輸入欄位（預設 `3503190424`）。
     - 預覽解析文字、顯示價格數字清洗遮蔽狀態。
   - 🩺 **臨床 SOAP 瀏覽 (SOAP Viewer)**：
     - 列表瀏覽 S/O/A/P 結構化病歷，支援關鍵字與條件篩選。
3. 掛載靜態資源:
   - 於 `src/api/app.py` 掛載 `StaticFiles(directory="src/web/static", html=True)` 至 `/admin` 或 `/app`。
4. 撰寫前端整合測試 `tests/test_web_ui.py`:
   - 驗證 `/admin` 或 `/app` 首頁成功回傳 200 OK 且包含核心 HTML 標記。
   - 驗證靜態 CSS / JS 正確提供。

## 3. 流水線加固要點（供 Claude 對抗性審查指引）
- XSS 防護：動態文字插入使用 `textContent` 或跳脫函式，嚴禁直接 `innerHTML` 插入未清洗的病患或問題文字。
- 敏感資訊防護：API 金鑰僅暫存於 session，不寫入 localStorage 或日誌。
