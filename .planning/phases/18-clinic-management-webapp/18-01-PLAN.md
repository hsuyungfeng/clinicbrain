# Plan 18-01: Web 後端管理與文件上傳 API 實作

## 1. 目標
在 FastAPI 服務層中建立診所管理專屬路由模組 `src/api/routes/admin.py`，提供文件上傳解析、待審衛教草稿檢索與簽核動作 API。所有端點嚴格掛載 `verify_admin_key` 認證，查詢連線採用唯讀連線，寫入操作走唯一權威路徑。

## 2. 實作任務（指派 Agy 3.6 Flash）
1. 建立 `src/api/routes/admin.py`:
   - `POST /api/v1/admin/upload`:
     - 接收檔案 `file: UploadFile`、`clinic_id: str`、`preview_only: bool = False`。
     - 副檔名白名單限制（`.docx`, `.xlsx`, `.pdf`），大小上限 15MB。
     - 呼叫 `markdown_convert` / `extract_text` 擷取內文，套用 `deidentify_text()` 與 `deep_mask_prices()`。
     - 若 `preview_only=False`，將合格問答段落寫入 `faq_cache`（`review_status='pending'`, `source_type='clinic_upload'`）。
   - `GET /api/v1/admin/review/faqs`:
     - 支援分頁（`limit`, `offset`）與篩選（`status`, `category`, `clinic_id`, `source_type`）。
     - 回傳包含 ID、主題、問題、答案、狀態、建立時間及 metadata（SOAP 溯源病歷筆數與關鍵字）。
   - `POST /api/v1/admin/review/faqs/{faq_id}/approve`:
     - 呼叫 `src/pageindex/faq_review.py:approve_faq()`。
   - `POST /api/v1/admin/review/faqs/{faq_id}/reject`:
     - 呼叫 `src/pageindex/faq_review.py:reject_faq()`。
   - `GET /api/v1/admin/review/summary`:
     - 提供審核儀表板摘要（pending 總數、special 待審數、general 待審數、approved 總數）。
2. 掛載路由:
   - 於 `src/api/app.py` 中掛載 `admin_router`。
3. 撰寫單元與整合測試 `tests/test_admin_api.py`:
   - 測試未帶 `X-API-Key` 時回傳 401（Fail-Closed）。
   - 測試文件上傳解析（Mock 上傳 DOCX/XLSX），驗證價格數字遮蔽與去識別化。
   - 測試 FAQ 列表查詢、核准與駁回動作。

## 3. 流水線加固要點（供 Claude 對抗性審查指引）
- 檔案路徑安全（防 Directory Traversal）。
- 連線模式隔離（唯讀連線 vs 寫入連線）。
- 大檔案上傳 DoS 防護。
