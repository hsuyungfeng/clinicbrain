# Phase 37: 選項 A（36 項基層 ICD-10 疾病升格寫入 `page_index_trees`）＋ 選項 B（Native Harness² 擴展至 FAQ 生成與推理樹提煉）— 實作計畫 (37-01-PLAN)

## 1. 階段目標 (Goal)
同步完成兩項核心升級：
1. **選項 A（Primary Care 36 ICD-10 Diseases $\rightarrow$ `page_index_trees` 臨床推理樹升格與檢索整合）**：
   - 升級 `src/pageindex/db_writer.py:upsert_trees()`，支援 `category == "general"` 且 `clinic_id is None` 的一般醫學共用臨床推理樹（維持 `category == "special"` 缺 `clinic_id` 時嚴格拋出 `ValueError` 的防線）。
   - 於 `src/visual/icd10_catalog.py` 新增 `entry_to_page_index_tree(entry) -> dict` 與升級 `seed_icd10_catalog(..., seed_trees=True, approve_trees=False)`，將 `data/icd10/primary_care_36_catalog.json` 內 36 項疾病的四段式 `clinical_summary`（`clinical_presentation` $\rightarrow$ `pre_op`、`pathophysiology` $\rightarrow$ `procedure`、`management_care` $\rightarrow$ `post_op_short`、`red_flags_prevention` $\rightarrow$ `maintenance`）透過唯一權威寫入路徑 `upsert_trees()` 寫入 `page_index_trees`（`doc_id = entry["topic_key"]`, `clinic_id = None`, `category = "general"`）。
   - 升級 `src/query/search.py:search_page_index_trees()`：當傳入特定 `clinic_id` 時，若 `include_general: bool = False`（預設維持 `False` 向後相容既有診所隔離測試），只查 `clinic_id = ?`；並於 `src/pageindex/rag_ask.py` 支援同時檢索診所專屬樹與一般醫學共用樹，且在 `src/general/consult.py`（一般醫療諮詢）與 `tree_navigator.py` 直接命中這 36 棵基層疾病推理樹。
2. **選項 B（Text Native Harness²：將雙層遞迴馬具擴展至 `answer_generator.py` 與 `tree_distiller.py`）**：
   - 建立 `src/pageindex/text_harness.py`：
     - **治理級教訓匹配 (`select_text_lessons`, `format_text_lessons_for_prompt`)**：共用 `data/visual/harness_lessons.json` 的 12 條專科臨床教訓，為 FAQ 衛教答案生成與臨床推理樹提煉注入跨任務防護欄（建議專業詞彙、禁用跨科別錯置詞彙）。
     - **FAQ 答案對齊評分器與精煉提示詞 (`score_faq_answer_alignment`, `build_faq_critique_prompt`)**：對通過合規檢驗的候選答案，評分其主題關鍵詞覆蓋率、段落結構充實度、是否誤觸跨科別禁用詞（`0.0 ~ 1.0`），並在 `k_candidates > 1` 時產生針對性精煉 Prompt。
     - **推理樹四段式對齊評分器與精煉提示詞 (`score_tree_distillation_alignment`, `build_tree_critique_prompt`)**：對通過 `validate_tree_segment` 的四段式推理樹，評分其與來源文件的臨床雙字詞覆蓋率、四階段（`pre_op`, `procedure`, `post_op_short`, `maintenance`）內容獨立性（不重複複製貼上）、各段字數充實度與教訓合規度（`0.0 ~ 1.0`）。
   - 升級 `src/pageindex/answer_generator.py:generate_answer_for_faq()` 與 `src/pageindex/batch_answer_job.py`：支援 `k_candidates: int = 1` 與 `recursion_mode: str = "sequential"`，注入治理教訓並於 metadata 記錄 `harness_score`、`harness_k`、`harness_mode`。
   - 升級 `src/pageindex/tree_distiller.py:distill_tree_from_text()`：支援 `k_candidates: int = 1` 與 `recursion_mode: str = "sequential"`，自動注入治理教訓並在多候選探索時挑選最高分四段式推理樹寫入資料庫。
