關鍵設計（已定案，勿更動）：
1. 單一檢查函式 `check_auth_config` 放 `src/api/security.py`，啟動腳本與 app lifespan 共用，禁止兩份邏輯。
2. 取捨：只檢查腳本會被 `uvicorn src.api.app:app` 直接繞過；只檢查 lifespan 則腳本會先印 banner 才失敗、且錯誤訊息被 uvicorn log 包裹。故兩處都檢查：腳本在啟動 uvicorn 前 fail-fast（乾淨的 stderr + exit code 2），lifespan 作為最後防線（uvicorn 直啟、systemd 改寫 ExecStart 亦被擋）。
3. 開發旗標必須映射為環境變數：`--allow-no-auth` 在 main() 內同時設 `config.allow_no_auth = True` 與 `os.environ["CLINICBRAIN_ALLOW_NO_AUTH"] = "1"`，因為 `--reload`/`workers>1` 子行程只繼承環境變數，不繼承 main() 事後改動的 config。
4. 空字串/純空白金鑰視為「未設定」。
5. 金鑰與開發旗標同時存在時，金鑰優先（強制驗證，不視為開發模式、不印警告）。
6. `verify_admin_key` fail-closed：無金鑰且 `allow_no_auth` 為 False 時回 503（繁體中文 detail），作為縱深防禦。
