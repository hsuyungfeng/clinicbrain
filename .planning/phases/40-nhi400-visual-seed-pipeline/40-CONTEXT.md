# Phase 40: 台灣健保第 201-400 項次級盛行疾病動畫擴充管線與權威輸入種子

## 1. 階段定位與目標
依據使用者指示，延續 Phase 39 成功建立之 200 大核心疾病動畫管線，進一步向台灣基層門診次級盛行率、特定年齡層與專科轉診範疇擴展（第 201 至 400 項疾病與症狀，涵蓋西醫 120 項、中醫 50 項、牙醫 30 項，共計 200 筆全新臨床主題）。

本階段的核心任務為：
1. **權威輸入種子建檔**：將第 201～400 項標準化收錄至 `data/nhi_primary_care_201_400.json`，並與正式庫現有前 200 大主題（`visual_assets` 及 `nhi_primary_care_200.json`）進行嚴格雙向去重篩選，確保 100% 零重複、零衝突。
2. **專科藍圖與圖元語意擴展**：針對次級疾病特異性機轉（耳鼻喉聲帶哮吼、眼科黃斑部玻璃體、泌尿精索前列腺、進階牙周 GTR 與顯微根管、中醫長強挑刺與特種針法），升級 `visual_engine.js` 與後端藍圖參數。
3. **DeepSeek / 本機雙模規模化生成**：沿用 24 秒（3 幕 × 8 秒）Typed IR 規範與自我修復閉環（Self-Healing Loop），批次生成 201～400 項之臨床解說動畫草稿。
4. **Herdr 多 Agent 驗收與安全入庫**：由 Hermes Agent 執行 Playwright 確定性渲染測試與無阿拉伯數字法規審計，草稿入庫（`pending`）並呈現在後台全景矩陣，待醫師簽核昇華。

## 2. 核心約束與醫療法規標準
- **雙向去重鐵則**：第 201～400 項清單必須精確排除正式庫已有的前 200 項（包含 88 筆歷史專科/基層樹與 Phase 39 的 114 筆 `nhi-*` 資產），所有新生成資產之 `topic_key` 格式為 `nhi-w201`～`nhi-w320`、`nhi-c321`～`nhi-c370`、`nhi-d371`～`nhi-d400`。
- **24 秒動畫規範**：嚴格每幕 8.0 秒（3 幕總計 24.0 秒），杜絕時長浮動。
- **零阿拉伯數字與合規鐵則**：全文本嚴禁半形或全形阿拉伯數字（0-9、０-９），一律採用中文數字；零價格洩漏；零保證療效；場景 3 結尾強制附帶「需由醫師當面評估」免責條款。
- **Fail-Closed 審核流程**：所有生成資產預設為 `pending`，經後台醫師簽核後自動昇華全院通用（`clinic_id = NULL`）。
