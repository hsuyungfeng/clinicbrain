# 40-03-PLAN: 201-400 規模化編譯器與 DeepSeek/本機雙模自癒生成管線

## 1. 目標 (Objective)
建立適用於第 201 至 400 項之規模化編譯器與自動化批次生成管線，支援雲端 DeepSeek API 與本機 8080 `llama-server` 雙模平滑切換，並嵌入 `validate_ir` 自動自癒修復迴圈（Self-Healing Retry Loop），確保 200 筆新資產皆精準符合 24 秒與零違規醫療法規約束。

## 2. 交付成果 (Deliverables)
1. `scripts/build_nhi400_manifest.py`：
   - 讀取 `data/nhi_primary_care_201_400.json`。
   - 為每項疾病預先組裝三幕臨床推理引導提示（Prompt）、藍圖推薦與關鍵字清單，輸出 `data/visual/nhi400_manifest.json`。
2. `scripts/generate_nhi400_visual_batch.py`：
   - 驅動 DeepSeek API 或本機 Qwen3.8-27B 進行批量生成。
   - 實作自動自癒迴圈：捕捉 `forbidden_phrase`、`schema_error`、`text_unsafe`、`digit_detected` 等錯誤，自動將具體違規字串組裝反饋提示模型重新修正。
3. `scripts/run_v2_scale_400.py`：
   - 端到端一鍵執行腳本（含前置去重比對、Manifest 編譯、批次生成與產物統計報告）。
4. `tests/test_nhi400_batch_generator.py`：
   - 驗證 Manifest 編譯產出 200 筆獨立規格任務。
   - 模擬自癒迴圈在遇到阿拉伯數字或保證療效時能成功攔截並自癒修復。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] Manifest 編譯腳本成功產出 200 筆任務清單。
- [ ] 自癒生成管線通過 mock 測試與 dry-run 驗證。
- [ ] 單元測試全數通過（`pytest tests/test_nhi400_batch_generator.py`）。
