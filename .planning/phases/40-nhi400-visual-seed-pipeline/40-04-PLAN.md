# 40-04-PLAN: Herdr 多代理協同驗收、Playwright 抽幀審計與全景矩陣草稿入庫

## 1. 目標 (Objective)
透過 Herdr / Hermes 代理人進行 Playwright 無頭瀏覽器渲染驗收與視覺抽幀審計，確認新生成的 200 部次級專科動畫在真實 DOM 環境中運行流暢無崩潰；將審驗合格之草稿批次入庫至正式資料庫 `clinic.db`（`review_status = 'pending'`），並於管理後台全景矩陣呈現，完成專案文檔與規範更新。

## 2. 交付成果 (Deliverables)
1. `tests/test_nhi400_browser_render.py`：
   - 使用 Playwright 執行無頭瀏覽器確定性 seek 測試。
   - 抽檢 201-400 各專科關鍵影格，確認文字不重疊、圖元幾何座標不越界、無半形阿拉伯數字殘留。
2. `scripts/stage_nhi400_to_db.py`：
   - 提供安全入庫工具，支援 `--allow-prod-db`。
   - 走正規 UPSERT 機制將 200 筆草稿安全匯入 `visual_assets`，保留既有資料不受破壞。
3. 管理後台全景矩陣擴充驗證：
   - 驗證 Web 管理後台能正常載入並分頁呈現 1～400 完整健保疾病分類樹。
   - 支援醫師在後台點擊簽核，確認自動昇華引擎（Auto-Promotion）正確生效。
4. 專案文件同步：
   - 更新 `AGENTS.md`、`README.md` 與 `.planning/ROADMAP.md`。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] Playwright 瀏覽器渲染測試全數通過（`pytest tests/test_nhi400_browser_render.py`）。
- [ ] 200 筆第 201～400 項草稿成功入庫，且資料庫總資產數收斂為 400 筆無重複資產。
- [ ] 後台「🎬 待簽核動畫」分頁正常播放與審核。
