# 40-01-PLAN: 健保 201-400 權威種子目錄建檔與全庫去重防禦契約

## 1. 目標 (Objective)
建立衛福部健保署基層門診第 201 至 400 項（共 200 項）標準化權威種子目錄 `data/nhi_primary_care_201_400.json`（涵蓋西醫 120 項、中醫 50 項、牙醫 30 項），並升級 `src/visual/nhi_dedup.py` 去重檢驗模組，嚴格確保新目錄與前 200 項（`nhi_primary_care_200.json` 與 `clinic.db` 中現有資產）達成 100% 零重複、零衝突。

## 2. 交付成果 (Deliverables)
1. `data/nhi_primary_care_201_400.json`：
   - 收錄 200 項完整條目（`W201`～`W320`、`C321`～`C370`、`D371`～`D400`）。
   - 每筆條目包含：`id`, `system`, `category`, `name`, `icd10`, `alias`, `keywords`, `clinical_feature`, `recommended_blueprint`。
2. `src/visual/nhi_dedup.py` 擴充：
   - 新增 `verify_seed_separation(seed_200_path, seed_400_path, db_conn)` 函式。
   - 執行雙向 cross-check，比對名稱、ICD-10-CM 代碼與主要同義關鍵字，若有任何碰撞立即報警。
3. `tests/test_nhi400_seed_integrity.py`：
   - 驗證 `data/nhi_primary_care_201_400.json` 恰好 200 筆，無缺失欄位。
   - 驗證所有 ICD-10-CM 編碼均符合標準醫療編碼格式。
   - 驗證所有條目之 `recommended_blueprint` 皆屬於 ClinicBrain 合法 11 大藍圖之一。
   - 驗證與現有 200 筆正式庫動畫資產無任何名稱或別名衝突。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] `data/nhi_primary_care_201_400.json` 建檔完備且通過 JSON Schema 檢核。
- [ ] 執行去重防禦檢驗，比對正式庫 200 筆資產回報 0 衝突、0 誤殺。
- [ ] 專屬單元測試全數通過（`pytest tests/test_nhi400_seed_integrity.py`）。
