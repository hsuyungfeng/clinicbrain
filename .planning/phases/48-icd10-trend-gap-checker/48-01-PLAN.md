# Plan 48-01: 診斷碼擷取與排行模組 (`src/soap/icd10_stats.py`)

## Objective
建立 `src/soap/icd10_stats.py`，支援從 `soap_records` 或外部聚合頻率表擷取並統計診所常用 ICD-10-CM 診斷碼排行，並與 `nhi_catalog_1_400` 對齊產出標準疾病主題清單，作為後續衛教覆蓋率檢查與草稿生成的上游資料來源。

## Tasks

### Task 1: 實作 ICD-10-CM 擷取與雙來源排行引擎
- **File**: `src/soap/icd10_stats.py`
- **Details**:
  1. 定義預編譯正則 `_ICD10_RE = re.compile(r"\b([A-TV-Z][0-9][0-9A-Z](?:\.[0-9A-Z]{1,4})?)\b", re.IGNORECASE)`（排除非診斷碼之常見干擾如純英文單字，並正規化為大寫）。
  2. 實作 `extract_icd10_codes(text: str) -> list[str]`：從病歷評估文字擷取去重後的 ICD-10 代碼清單（保留同一病歷中出現的多個不同診斷碼，單筆病歷重複出現同一碼僅計 1 次）。
  3. 實作 `rank_icd10_from_soap(conn, clinic_id: Optional[str] = None, *, since_days: Optional[int] = None, limit: int = 20) -> list[dict]`：
     - 安全檢查 `soap_records` 表是否存在（不存在則安全回傳 `[]`）。
     - 查詢 `assessment` 與 `raw_text`，累計各 `icd10` 次數並依 `(count DESC, icd10 ASC)` 排序。
  4. 實作 `rank_icd10_from_aggregated(items: Sequence[dict], *, limit: int = 20) -> list[dict]`：
     - 支援外部同步傳入的 `[{"icd10": "J06.9", "count": 18, "label": "..."}]` 聚合清單，合併同碼計數、過濾無效代碼與非正整數計數、排序後回傳。

### Task 2: 實作 `nhi_catalog_1_400` 對齊與整合入口
- **File**: `src/soap/icd10_stats.py`
- **Details**:
  1. 實作 `align_icd10_with_nhi_catalog(conn, ranked_codes: Sequence[dict]) -> list[dict]`：
     - 檢查 `nhi_catalog_1_400` 表是否存在（不存在則回傳 `catalog_matched=False` 之原始條目）。
     - 對齊順序：
       1. 精確匹配 `UPPER(icd10) = ?`（支援目錄內逗號或斜線分隔多碼情況）。
       2. 若無精確匹配，取前 3 碼大類（如 `J06`）以 `UPPER(icd10) LIKE ? ESCAPE '\'`（重用 `src.query.search.escape_like`）匹配最接近項目。
       3. 若有傳入 `label`（中文診斷描述）且仍未命中，退回呼叫 `src.query.nhi_index.search_nhi_catalog(conn, label, limit=1)`。
     - 回傳標準結構：`icd10`, `count`, `catalog_matched`, `topic_key`, `disease_name`, `system`, `clinical_feature`, `keywords`, `visual_available`。
  2. 實作 `get_top_clinic_diseases(conn, clinic_id: Optional[str] = None, *, aggregated_counts: Optional[Sequence[dict]] = None, since_days: Optional[int] = None, limit: int = 20) -> list[dict]`：統一入口，合併 `soap_records`（若存在）與 `aggregated_counts`（若提供）後執行對齊。

### Task 3: 撰寫隔離單元測試
- **File**: `tests/test_icd10_stats.py`
- **Details**:
  - 使用 `sqlite3.connect(":memory:")` 或 `tmp_path` 隔離資料庫，建立測試用 `soap_records` 與 `nhi_catalog_1_400`（含 `nhi_catalog_fts`）。
  - 測試案例涵蓋：
    1. `extract_icd10_codes` 精確擷取（`J06.9`, `E11.9`, `L20.9`, `K21`）與大小寫正規化、單筆去重、忽略一般單字。
    2. `rank_icd10_from_soap` 依診所與時間區間統計排行；`soap_records` 不存在或為空時安全回傳 `[]`。
    3. `rank_icd10_from_aggregated` 合併重複碼、過濾無效格式。
    4. `align_icd10_with_nhi_catalog` 精確匹配、3 碼大類 fallback、名稱 fallback 及未命中標記。
    5. 驗證回傳欄位無病患個資。
