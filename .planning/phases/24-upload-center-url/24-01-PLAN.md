## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 瀏覽器表單 → /upload name 欄位 | 使用者可輸入任意字串，可能夾帶個資、金額或注入字元 |
| name → topic_key／題目佔位字 → 資料庫與公開回應 | 名稱會進入公開可見的 FAQ 主題與題目文字 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Information Disclosure | name 含身分證／電話 | mitigate | validate_display_name 比對 deidentify_text 結果，不一致即 400 |
| T-24-02 | Tampering | name 含金額、促銷字樣寫入對外內容 | mitigate | 比對 deep_mask_prices 結果，不一致即 400 |
| T-24-03 | Tampering | name 含路徑、控制字元或 SQL 特殊字元 | mitigate | NFKC 正規化後以白名單 regex 判定；參數化 SQL 已存在 |
| T-24-04 | Information Disclosure | 400 錯誤回應回顯輸入值（可能含個資） | mitigate | 錯誤訊息固定字串，不插入輸入值；測試斷言 detail 不含原文 |
| T-24-05 | Denial of Service | 超長名稱 | mitigate | 長度上限 80 字元 |
| T-24-06 | Tampering | 同名覆寫既有資料（R4 退化） | mitigate | 保留既有 UNIQUE(clinic_id, topic_key, question) 與 upsert_faqs 行為；未填名稱同檔名回歸測試；批量同檔名由測試鎖定並由前端規則避免 |
