- [ ] CONSTRAINT: 繁體中文 Exclusive — Every LLM output must use繁體中文 only. English or simplified Chinese outputs violate compliance requirements.
- [ ] CONSTRAINT: FTS5 Chinese Tokenizer — SQLite FTS5's `unicode61` tokenizer does NOT segment CJK text; any new/changed FTS5 virtual table MUST explicitly set `tokenize='trigram'` and be verified with a real Chinese-language MATCH query before being considered done. Grep `sqlite_master` for `fts5` to confirm after any schema change.
- [ ] CONSTRAINT: FTS5 trigram MATCH requires the WHOLE query string to match contiguously — a full natural-language sentence will almost never match even if it contains a term that exists verbatim in the data. This bit TASK-005 hard (see below). Any new code that searches these FTS5 tables MUST go through `src/query/router.py`'s `extract_search_terms()` first, not pass raw user input straight to `search_text()`/`MATCH`.
- [ ] CONSTRAINT: page_index_trees writes MUST be incremental UPSERT via `src/pageindex/db_writer.py`'s `upsert_trees(conn, trees, source_type)` — never `INSERT OR REPLACE`, never a second competing write path.
- [ ] CONSTRAINT: Record-count sanity — `wc -l` on NHI CSVs does NOT equal record count (multi-line free-text fields contain embedded newlines). Always verify via `csv.DictReader` row iteration.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Price Leakage | Raw TWD prices appear in output | blocking | `mask_prices()` in `src/query/router.py`, applied to every result field |
| Route Confusion | `general` route incorrectly includes clinic hours/info | blocking | `handle_query()` only fetches `clinic_info`/`clinic_hours` when route is `special` AND a clinic-ops keyword matched |
| Language Drift | Mixed simplified/traditional Chinese | blocking | SFT dialogue corpus (medical_o1_sft_Chinese.json) is Simplified Chinese — never feed it into any Traditional-Chinese-only pipeline |
| Silent FTS5 tokenizer drift | New/edited FTS5 table without explicit `tokenize='trigram'` silently reverts to `unicode61`, breaking CJK matching entirely | blocking | grep `sqlite_master` for all `fts5` tables after any schema change; run a live Chinese MATCH query per table |
| Full-sentence FTS failure | Passing a raw natural-language question to FTS5 `MATCH` returns zero hits even when the answer term exists verbatim in the data | blocking | Always route search queries through `extract_search_terms()` before calling `search_text()`/`MATCH` |
| Wholesale overwrite defeats versioning | `INSERT OR REPLACE` on `page_index_trees` resets `created_at`, breaks `content_version` | blocking | Use `db_writer.upsert_trees()`; never write a second competing seed path |
| CSV row-count miscounting | `wc -l` overcounts CSV records with embedded newlines | advisory | Count records via `csv.DictReader`, not `wc -l` |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
