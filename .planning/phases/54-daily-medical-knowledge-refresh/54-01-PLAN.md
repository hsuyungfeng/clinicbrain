# Plan 54-01: 提案資料表與權威醫學白名單採集器（Wave 1）

## Tasks

### Task 1: 建立 `knowledge_refresh_proposals` 與 `knowledge_refresh_log` Schema
- 更新 [src/db/clinic_schema.sql](file:///home/hsuyungfeng/DevSoft/clinicbrain/src/db/clinic_schema.sql) 並於 `src/refresh/schema.py` 實作冪等 `ensure_refresh_tables(conn)`：
  - `knowledge_refresh_proposals`: `id`, `target_type` (`'faq' | 'tree' | 'visual_edu'`), `target_key` (FAQ 為 `str(faq_id)`、Tree 為 `doc_id`、Visual 為 `topic_key`), `clinic_id`, `title`, `source_url`, `source_domain`, `evidence_summary`, `diff_summary`, `current_snapshot`, `proposed_json`, `status` (`'pending' | 'approved' | 'rejected'`), `created_at`, `reviewed_at`；並建立部分唯一索引 `CREATE UNIQUE INDEX IF NOT EXISTS idx_refresh_proposals_pending ON knowledge_refresh_proposals(target_type, target_key) WHERE status = 'pending'` 防止重複待審提案。
  - `knowledge_refresh_log`: `target_type`, `target_key`, `last_verified_at`, `last_status` (`'unchanged' | 'proposed' | 'error'`), `last_source_url`, `PRIMARY KEY (target_type, target_key)`。

### Task 2: 實作權威醫學白名單採集器 `src/refresh/sources.py`
- 定義 `ALLOWED_MEDICAL_DOMAINS`（涵蓋 `mohw.gov.tw`, `cdc.gov.tw`, `fda.gov.tw`, `nhi.gov.tw`, `hpa.gov.tw`, `eutils.ncbi.nlm.nih.gov`, `pubmed.ncbi.nlm.nih.gov`, `ntuh.gov.tw`, `vghtpe.gov.tw`, `cgmh.org.tw`, `cmuh.cmu.edu.tw`）與 `is_allowed_medical_url(url)`：
  - 強制 `https://`、標準埠 443、主機名稱精確比對 `host == domain or host.endswith('.' + domain)`（嚴防 `xcdc.gov.tw` 前綴繞過），並復用 [src/scraper/policy.py](file:///home/hsuyungfeng/DevSoft/clinicbrain/src/scraper/policy.py) 的 `resolve_public_addresses()` / `is_public_address()` 拒絕內網 IP 與 DNS rebinding，所有 HTTP 請求關閉自動重導向（`follow_redirects=False`）或對重導向目標重複檢核白名單。
- 實作 `fetch_pubmed_evidence(query_en: str, max_results: int = 3)`（呼叫 `esearch.fcgi` + `efetch.fcgi` 取得近 2 年相關實證摘要）。
- 實作 `parse_rss_feed(xml_text: str, base_url: str)` 與 `fetch_official_feeds(feed_urls)`（支援衛福部/CDC/TFDA RSS 公告，透過 `xml.etree.ElementTree` 解析並過濾白名單）。

### Task 3: 建立 `tests/test_refresh_sources.py`
- 測試白名單放行／拒絕邊界（含子網域、假網域如 `cdc.gov.tw.evil.com` 與前綴繞過如 `xcdc.gov.tw`、內網 IP）。
- 以 Mock `httpx` 回應測試 PubMed XML/JSON 與官方 RSS 解析，以及 `ensure_refresh_tables()` 冪等性。
