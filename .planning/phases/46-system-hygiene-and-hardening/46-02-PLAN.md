# 46-02-PLAN: P0/P1 API 安全防禦加固、非同步事件迴圈解鎖與背景渲染護欄

## 1. 目標 (Objective)
修補 API 層的高風險安全組態（CORS 反射憑證、時序側信道比對），解決 FastAPI 事件迴圈阻塞問題，並為背景影片渲染加入防重入鎖與子行程執行逾時機制。

## 2. 交付成果 (Deliverables)
1. **CORS 安全收緊與白名單機制 (`src/api/app.py` & `src/api/config.py`)**：
   - 移除 `allow_origins=["*"]` 與 `allow_credentials=True` 同時並存之漏洞。
   - 支援 `CLINICBRAIN_CORS_ORIGINS` 環境變數（逗號分隔白名單），預設僅允許本機 `http://127.0.0.1:8000` 與 `http://localhost:8000`。
   - 若允許任意來源則必須強制關閉 `allow_credentials=False`。
2. **常數時間 API 金鑰認證 (`src/api/dependencies.py`)**：
   - 使用 Python 內建 `secrets.compare_digest` 比對 `X-API-Key` 與 `config.admin_api_key`，防範時序側信道攻擊（Timing Attack），落實 `AGENTS.md` 規劃之 AUTH-04。
3. **解除檔案上傳事件迴圈阻塞 (`src/api/routes/admin.py`)**：
   - 將 `upload_admin_file` 中的同步運算（MarkItDown/DOCX 萃取、OpenCC 繁簡轉換、去識別化與 SQLite 寫入）封裝為背景工作函式，透過 `starlette.concurrency.run_in_threadpool` 在執行緒池中非同步執行，釋放主事件迴圈以處理健康檢查與查詢請求。
4. **影片渲染防重入互斥鎖與 Subprocess 逾時 (`src/visual/video_queue.py` & `src/api/routes/admin.py`)**：
   - 在記憶體維護 `_rendering_topics: set[str]` 互斥鎖，避免同一主題被重複點擊同時渲染引發檔案競爭損壞。
   - `subprocess.run(ffmpeg_cmd, check=True)` 加上 `timeout=180` 秒保護，防止編碼卡死永久佔用背景執行緒。
   - 渲染時先輸出暫存檔 `.tmp.mp4`，成功完成後再原子替換為最終檔案。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] CORS 組態符合安全性要求，不允許萬用字元與憑證共存。
- [ ] `verify_admin_key` 使用常數時間比對且現有認證測試 100% 通過。
- [ ] 檔案上傳端點在高負載解析時不阻塞 `/health` 探測。
- [ ] 影片渲染具備防重入保護與 180s 逾時控制。
