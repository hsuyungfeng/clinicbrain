# Plan 21-02: Web App 臨床決策樹視覺化檢視與醫師簽核介面

## 1. 目標
在 Web App（`src/web/static/`）新增「臨床推理樹簽核」分頁，呈現四段式卡片（術前評估、療程步驟、術後照護、長期維持），支援內聯編輯與醫師填寫專屬權威醫囑（`*_physician_notes`），並在上傳中心支援直接選擇提煉為臨床推理樹。

## 2. 實作任務（指派 Agy 3.6 Flash）
1. **介面結構擴充 (`index.html`)**：
   - 頂部導航列新增頁籤：
     - **【🌳 臨床推理樹簽核】** (`data-tab="tab-trees"`)。
   - 總覽儀表板新增決策樹統計卡片：
     - 「待簽核推理樹」與「已發布推理樹」。
   - 新增內容區塊 `#tab-trees`：
     - 篩選控制項：狀態過濾（待簽核 / 已發布 / 已駁回 / 全部）、診所代碼。
     - 決策樹清單容器 (`#treesContainer`) 與分頁控制項。
   - 擴充檔案上傳中心（`#tab-upload`）：
     - 增加提煉目標切換鈕（單選）：
       - 🔘 提煉為常見問答（FAQ 草稿）
       - 🔘 提煉為臨床決策推理樹（PageIndex Tree）
   - 新增決策樹編輯對話框（Modal）：
     - 包含標題、Slug、四段內容編輯框，以及四個**「👨‍⚕️ 醫師特約權威醫囑」**獨立金黃色醒目輸入框。
2. **前端邏輯實作 (`app.js`)**：
   - 載入並渲染決策樹清單：
     - 四段式網格卡片佈局，高對比度標記各階段與醫師備註。
   - 醫師操作行為綁定：
     - 點擊【✏️ 編輯/填寫醫囑】：彈出 Modal 載入既有內容，送出呼叫 `PUT /api/v1/admin/trees/{id}`。
     - 點擊【✅ 簽核發布】：呼叫 `POST /api/v1/admin/trees/{id}/approve`，狀態即時變更為綠色「已核准」。
     - 點擊【❌ 駁回】：呼叫 `POST /api/v1/admin/trees/{id}/reject`。
   - 上傳分流支援：
     - 當使用者選擇「提煉為臨床決策推理樹」時，檔案或文字送往 `POST /api/v1/admin/trees/distill`。
   - 儀表板統計更新整合。
3. **視覺樣式美化 (`style.css`)**：
   - 為四段式結構設計清晰的階段時間軸或分欄卡片。
   - 為「醫師特約醫囑」設計專屬專業金色邊框與徽章，彰顯權威性。
4. **前端測試編寫 `tests/test_web_ui_trees.py`**：
   - 驗證 HTML 中包含 `tab-trees`、四段卡片結構與醫師醫囑欄位。
   - 驗證 JS 綁定決策樹讀取、簽核與駁回事件。

## 3. 驗收標準
- `pytest tests/test_web_ui_trees.py` 通過，Web 介面操作流暢直覺。
