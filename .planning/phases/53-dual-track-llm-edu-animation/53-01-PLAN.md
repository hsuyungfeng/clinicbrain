# Plan 53-01: 新增 `care_redflag` 藍圖與渲染器支援（Wave 1）

## Goal
在視覺引擎與藍圖註冊表新增專用第 3 幕藍圖 `care_redflag`，讓衛教動畫第 3 幕能以視覺化動畫呈現「日常預防行動（左）＋ 急診紅旗警訊（右）＋ 一句話記牢（底）」。

## Tasks

### Task 1: 擴充 `src/visual/blueprints.py` 與 `src/visual/ir.py` 註冊 `care_redflag`
- 在 `BLUEPRINTS`（`blueprints.py`）與 `VALID_BLUEPRINTS`（`ir.py`）新增 `care_redflag` 定義與 `defaults`：
  - `care_items`：list[text], min=3, max=4, 每項 max_len=12（日常預防重點）
  - `red_flags`：list[text], min=2, max=4, 每項 max_len=12（急診警訊）
  - `myth_note`：text, max_len=24（常見迷思破解一句話，可選）
  - `takeaway`：text, max_len=36（一句話記牢）
  - `urgency_level`：int, min=1, max=5（控制右側紅旗脈衝強度）
- 確認 `validate_ir()`、`validate_params()` 與 `get_default_params("care_redflag")` 正常運作，且既有數字與禁止詞檢查仍由 `validate_visual_text()` 一致把關；場景層 `caption`（20–120 字）應作為衛教行動總結導語，避免逐字重複 `takeaway`。

### Task 2: 在 `src/web/static/visual_engine.js` 實作 `drawCareRedflag`
- 在 `blueprints` 新增 `care_redflag`（params、defaults、draw: `drawCareRedflag`）。
- 在 `resolveParams(blueprint, params)` 新增 `blueprint === "care_redflag"` 的邊界保護與截斷邏輯。
- 實作 `drawCareRedflag(ctx, params, u)`（嚴格限定面板垂直範圍在 `y: 80..396`，保留與 `drawSceneNarrativeOverlay` `y: 414..476` 字幕區及 `y: 480..500` 標籤列之間至少 18px 緩衝）：
  - 左半部（x: 42..386, y: 80..340）：依序隨進度 `u` 逐一亮起的綠色／青色預防行動膠囊（打勾圖示＋文字）。
  - 右半部（x: 414..758, y: 80..340）：紅旗急診警訊面板，隨 `u` 呈現平滑呼吸脈衝框線與警示燈號。
  - 底部（y: 350..396）：「一句話記牢」橫幅與迷思提示膠囊。
  - 全程使用 `pmSmooth` / `pmRange` 連續函式，確保無影格跳躍且字幕框不重疊。

### Task 3: 建立 `tests/test_care_redflag_blueprint.py`
- 驗證 `BLUEPRINTS["care_redflag"]` schema、合法與非法參數驗證。
- 使用 Playwright Chromium 掛載 `visual_engine.js` 渲染 `care_redflag` 場景（`u = 0.2, 0.6, 0.9`），斷言 `pageerror` 為空且 SVG DOM 含預防行動、紅旗警訊與一句話記牢文字。
