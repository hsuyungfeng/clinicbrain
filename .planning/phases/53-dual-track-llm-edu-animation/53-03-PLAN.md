# Plan 53-03: 雙軌前端 UI 整合與獨立可列印分享頁 `/edu/{topic_key}`（Wave 3）

## Goal
將 `edu_json` 接通至 API 與前端雙軌介面：在既有查詢與諮詢畫面動畫下方展開完整 7 段圖文衛教，並提供獨立可分享、支援 A4 單張列印的 `/edu/{topic_key}` 頁面。

## Tasks

### Task 1: 新增 API 端點與獨立頁面路由
- 在 [src/api/routes/visual.py](file:///home/hsuyungfeng/DevSoft/clinicbrain/src/api/routes/visual.py) 新增 `GET /api/v1/visual/edu/{topic_key}`（使用唯讀連線 `get_read_db`，比照 `_get_approved_visual_title()` 僅放行 `review_status = 'approved'` 之主題，未核准或不存在回傳 HTTP 404；回傳 `topic_key`、`title`、`edu`、`ir`、`video_url`、`share_url`，一律經 `deep_mask_prices()` 清洗）。
- 在 [src/api/app.py](file:///home/hsuyungfeng/DevSoft/clinicbrain/src/api/app.py)（根路由，**不可**置於含 `/api/v1/visual` 前綴的 `visual.py`）掛載 `GET /edu/{topic_key}` 回傳 `src/web/static/edu.html`（`FileResponse`，由 `edu.js` 依 URL path 讀取 `topic_key` 並向 API 載入資料）。

### Task 2: 建立獨立衛教單張頁面 `edu.html` + `edu.js`
- 頁首顯示主題標題、診所衛教免責標記、「列印 A4 單張」與「複製分享連結」按鈕。
- 上半部掛載 `ClinicVisual.mount()` 3 幕 SVG 動畫播放器（含播放/暫停/重播/章節跳轉，與 MP4 切換連結）。
- 下半部依 7 大區塊渲染：定義與結構重點、對比表格（響應式表格）、成因步驟流程與高風險膠囊、症狀與併發症警示樹、診斷方式表格、6 項預防行動與「常見迷思破解」框、急診紅旗醒目警示條與「一句話記牢」。
- 加入 `@media print` 樣式，列印時隱藏互動按鈕，保留清潔排版與關鍵結構摘要。

### Task 3: 整合至 `index.html` / `app.js` 與 `consult.html` / `consult.js`
- 在兩處既有動畫舞台下方新增可收合「📖 完整圖文衛教重點」面板與「↗ 獨立分享 / 列印」按鈕；若該筆資料尚未生成 `edu_json`，自動隱藏展開內容不報錯。
- 新增 `tests/test_edu_web_endpoints.py`（測試 `/api/v1/visual/edu/{topic_key}`、`/edu/{topic_key}` 回應、價格遮蔽與 Playwright 渲染 7 段卡片無 `pageerror`）。
