# Plan 19-02: 前端 UI 深度美化、全選/反選/浮動操作列與 AI 互動

## 1. 目標
升級 `src/web/static/`（`index.html`, `app.js`, `style.css`），全面美化介面視覺，實作全選/反選控制項、底部浮動批量操作列、單題「🤖 生成衛教解答」按鈕與答案內聯編輯功能。

## 2. 實作任務
1. 介面視覺美化 (`style.css` & `index.html`):
   - 現代醫療科技感調色：深海藍（`#0f172a`）頂欄、優雅青綠（`#059669`）主色與柔和白底。
   - 卡片邊框加細、陰影自然柔和，增設狀態標籤（例如「待生成答案」、「待核准」、「SOAP 提煉」）。
   - 加入載入動畫（Loading Spinner）與骨架屏（Skeleton Loading）。
2. 批量選擇與浮動工具列 (`app.js` & `index.html`):
   - 頂部工具列新增：
     - `☑️ 全選 (Select All)`
     - `🔄 反選 (Invert Selection)`
     - `⏹️ 清除 (Clear)`
     - 勾選總計標籤：`已選取 X / Y 筆`
   - 每張待審卡片左側增設大型 Checkbox，點擊卡片本體亦可快速切換選取。
   - 底部浮動操作列（Sticky Action Bar）：
     - 當勾選數量 > 0 時平滑滑入畫面底部。
     - 提供按鈕：【✅ 批量核准所選 (N)】、【❌ 批量駁回所選 (N)】。
     - 點擊後呼叫 `POST /api/v1/admin/review/batch`，處理完畢後平滑移除所有已簽核卡片並更新儀表板統計。
3. 單題 AI 答案生成與內聯編輯:
   - 若卡片答案為空或簡陋，顯示亮黃色警示標籤「⚠️ 答案待補齊」，並呈現【🤖 本地 LLM 生成解答】按鈕。
   - 點擊生成解答時顯示載入中旋轉圖示，成功後即時替換答案文字。
   - 答案卡片附帶【✏️ 編輯】按鈕，點擊後展開文字編輯框，修改後可儲存更新。
4. 前端測試擴充 `tests/test_web_ui_v2.py`:
   - 驗證更新後的 HTML 包含批量控制項（全選、反選、浮動列）與 AI 生成按鈕結構。

## 3. 驗收標準
- 前端能流暢執行全選、反選、批量核准，單題呼叫 LLM 生成答案無報錯。
