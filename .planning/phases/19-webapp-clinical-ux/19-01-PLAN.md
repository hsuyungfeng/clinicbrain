# Plan 19-01: 後端批量簽核、AI 答案生成與內聯編輯 API

## 1. 目標
在 `src/api/routes/admin.py` 與 `src/pageindex/faq_review.py` 中擴充批次處理、本地 LLM 衛教生成與內聯更新 API，支援單次批量核准/駁回與即時解答生成。所有端點嚴格掛載 `verify_admin_key` 認證。

## 2. 實作任務
1. 擴充 `src/pageindex/faq_review.py`:
   - 新增 `batch_review_faqs(conn, faq_ids: list[int], action: str) -> dict`:
     - 驗證 `action` 僅限 `'approve'` 或 `'reject'`。
     - 在單一交易中迭代處理，避免部分失敗。
     - 回傳 `{"success_count": int, "failed_count": int, "processed_ids": list[int]}`。
   - 新增 `update_faq_content(conn, faq_id: int, question: str | None = None, answer: str | None = None) -> bool`:
     - 允許更新問題或答案，更新前強制套用 `mask_prices()`。
2. 擴充 `src/api/routes/admin.py`:
   - 新增 `POST /api/v1/admin/review/batch`:
     - 接收請求體 `BatchReviewRequest`（`action: str`, `faq_ids: list[int]`）。
     - 限制 `faq_ids` 長度最大 100 筆。
     - 呼叫 `batch_review_faqs()` 並回傳處理結果。
   - 新增 `POST /api/v1/admin/review/faqs/{faq_id}/generate-answer`:
     - 讀取該題之 `question` 與診所背景。
     - 呼叫本地 `llama-server`（使用既有 prompt 與四層合規檢查）。
     - 若本地 LLM 未啟動，提供優雅降級回覆或清楚提示。
     - 將生成合格之衛教答案存入資料庫（狀態維持 `pending`），回傳生成文字。
   - 新增 `PATCH /api/v1/admin/review/faqs/{faq_id}`:
     - 接收 `UpdateFaqRequest`（`question: str | None`, `answer: str | None`）。
     - 內聯修訂更新。
3. 撰寫單元與整合測試 `tests/test_admin_batch_and_ai.py`:
   - 驗證 `batch` API 批量核准與駁回（單一請求處理多筆）。
   - 驗證 `generate-answer` API（Mock LLM 生成與價格清洗）。
   - 驗證 `PATCH` 內聯更新。

## 3. 驗收標準
- `pytest tests/test_admin_batch_and_ai.py` 全部通過。
