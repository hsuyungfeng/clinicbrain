## 3. Claude 對抗性審查與加固（指派 Claude 5.5 Sonnet）
審查全部改動，重點檢查：
1. **批量操作安全性**：
   - `batch` API 的 ID 陣列長度限制（防止大量記憶體耗盡或 DoS）。
   - 交易 rollback 邊界（任一重大錯誤不應留下半提交資料）。
2. **AI 生成答案安全**：
   - 呼叫本地 LLM 時是否強制過濾價格數字與就醫警訊。
   - LLM 回應 timeout 與斷網優雅降級。
3. **XSS 防護**：
   - 內聯編輯與 AI 生成答案在 DOM 插入時是否持續使用 `textContent` 或跳脫防護。
4. **規範文檔同步**：
   - 更新 `AGENTS.md`，新增「2.18 Web 臨床操作體驗與 AI 協同工作流（Phase 19 新增）」章節。
5. **加固測試**：`tests/test_phase19_hardening.py`。
