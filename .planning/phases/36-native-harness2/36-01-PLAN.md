# Phase 36: ClinicBrain Native Harness²（雙層遞迴自進化馬具）— 實作計畫 (36-01-PLAN)

## 1. 階段目標 (Goal)
借鏡 Google Research 2026 開源框架 **Harness² (Recursive Agent Harnessing for an Open World)** 的雙層遞迴（Task-Level Recursion 與 Harnessing-Level Recursion）核心精神，在不改動本地模型權重（`Qwen3.8-27B-FP8`）與零外部雲端依賴的前提下，於 `clinicbrain` 建構原生 **ClinicBrain Native Harness²** 優化引擎：

1. **任務級遞迴（Task-Level Recursion：`--k` 候選探索 ＋ 臨床語意對齊評分器 ＋ 結構化批評自癒）**：
   - 建立 `score_visual_ir_alignment(tree, ir)`：在 `validate_ir`（語法與合規硬防線）通過後，進一步針對「解剖與病理專一性」、「零罐頭模板殘留」、「場景一/二/三敘事連貫性」與「醫師手札（`*_physician_notes`）重點覆蓋率」進行 0.0～1.0 定量評分，並產出具體扣分原因（`penalties`）與修正建議（`suggestions`）。
   - 建立 `build_alignment_critique_prompt(base_prompt, ir, score_report)`：當 `--k > 1` 且候選分數未達優異門檻（`< 0.88`）時，將具體臨床與視覺落差轉化為針對性繁體中文重繪提示詞。
   - 升級 `autodraft_from_tree()` 與 `scripts/autodraft_visual_from_trees.py`，支援 `--k <int>`（預設 `1`）與 `--mode sequential|parallel`（預設 `sequential`），自動探索並遴選最高分之 Typed IR 寫入資料庫，且於 `metadata` 記錄 `harness_score`、`harness_k`、`harness_mode` 與 `harness_penalties`。

2. **治理級遞迴（Harnessing-Level Recursion：`data/visual/harness_lessons.json` 跨任務經驗記憶庫）**：
   - 建立持久化治理記憶庫 `data/visual/harness_lessons.json`，預載 Phase 31～35 累積之 12 條真實臨床與視覺矯正教訓（涵蓋產後媽咪改造腹直肌縫合 vs 臉部拉皮、FUE 毛囊鑽取 vs 脂肪離心、眼袋脂肪轉位、自體肋骨鼻雕、以及 6 大基層專科器官病理藍圖與非手術場景二/三規範）。
   - 於 `build_tree_visual_prompt()` 自動依據療程/疾病主題匹配對應之治理教訓（`select_lessons_for_tree`），動態注入 Prompt 防護欄。
   - 於 `src/visual/review.py` 的 `adopt_v2_candidate()` 與新增之經驗提煉函式 `record_review_lesson()` 串接治理級閉環：當 V2 候選取代舊版 V1 時，自動比對兩者藍圖、模式與關鍵詞差異並沉澱為新的治理教訓。

3. **子代理驗證馬具（Subagent Verification Harness：`scripts/harness_check.sh`）**：
   - 建立零長路徑參數的標準化驗證腳本 `scripts/harness_check.sh`，解決本地模型（`Hermes / Qwen3.8-27B`）執行超長 `pytest` 路徑時觸發 DRY 懲罰截斷的問題。

## 3. 詳細規格設計 (Detailed Specifications)

### 3.1 `data/visual/harness_lessons.json` 結構
```json
{
  "version": 1,
  "updated_at": "2026-10-27T17:20:00+08:00",
  "lessons": [
    {
      "lesson_id": "lesson-body-abdominoplasty",
      "scope": "topic_keywords",
      "match_terms": ["媽咪", "腹", "妊娠", "肚皮", "產後", "mommy", "abdomino"],
      "preferred_blueprint": "corset_platysmaplasty",
      "rule": "產後腹部拉皮與媽咪改造必須聚焦腹直肌分離縫合、腹壁筋膜收緊與肚臍重塑，嚴禁套用臉部拉皮或闊頸肌字眼。",
```

### 3.2 `src/visual/harness_optimizer.py` 核心函式介面
1. `load_harness_lessons(path: Optional[Path] = None) -> list[dict[str, Any]]`
   - 讀取 `data/visual/harness_lessons.json`（若不存在或損毀則安全回傳內建預設清單）。
2. `select_lessons_for_tree(tree: dict[str, Any], lessons: Optional[list[dict[str, Any]]] = None, max_lessons: int = 3) -> list[dict[str, Any]]`
   - 比對 `tree` 的 `title`、`doc_id`、`pre_op`、`procedure`、`post_op_short`、`maintenance` 與各手札文字，計算 `match_terms` 命中數，回傳最相關的前 `max_lessons` 條教訓。
3. `format_lessons_for_prompt(lessons: list[dict[str, Any]]) -> str`
   - 將命中的治理教訓格式化為繁體中文 Prompt 區塊（例如 `【Harness² 跨任務治理經驗防護欄（請嚴格遵守）】`），明確列出核心規則、建議詞彙與禁用跨科別錯置詞彙。
4. `score_visual_ir_alignment(tree: dict[str, Any], ir: dict[str, Any], lessons: Optional[list[dict[str, Any]]] = None) -> dict[str, Any]`
   - 對已通過 `validate_ir` 的 `ir` 進行臨床語意與視覺品質評分，回傳：
     ```python
     {
         "score": float,          # 0.0 ~ 1.0（四捨五入至小數第 4 位）
         "passed_threshold": bool,# score >= 0.85
         "penalties": list[str],  # 繁體中文具體扣分項目
         "suggestions": list[str],# 繁體中文具體改進建議
         "breakdown": {
             "lexical_specificity": float,
             "lesson_compliance": float,
             "scene_diversity": float,
             "physician_note_alignment": float,
         }
     }
     ```
   - 評分維度：
     - **A. 教訓合規度 (`lesson_compliance`, 權重 0.35)**：檢查是否誤觸命中教訓的 `negative_terms`（每命中一個扣分並記錄具體禁用詞），以及是否涵蓋 `positive_terms` 與建議藍圖。
     - **B. 臨床詞彙專一性 (`lexical_specificity`, 權重 0.30)**：從 `tree` 萃取臨床關鍵詞（排除一般停用詞），檢查 IR 的 `title`、`keywords`、各幕 `caption`、`labels` 與 `step_labels`/`milestones` 是否具備高專一性，並偵測罐頭泛用詞（如 `"重要標籤一"`、`"步驟一"`、`"第一階段"`、`"問題狀態"`、`"建議方案"`）。
     - **C. 場景敘事差異與豐富度 (`scene_diversity`, 權重 0.20)**：檢查三幕的 `title` 與 `caption` 是否高度重複、各幕 `caption` 長度是否充實（`>= 32` 字最佳）、標籤是否具備明確語意。
     - **D. 醫師手札對齊度 (`physician_note_alignment`, 權重 0.15)**：若 `tree` 含非空的 `*_physician_notes`，檢查手札核心詞彙是否反映於視覺解說卡中；若無手札則給予滿分基準。
5. `build_alignment_critique_prompt(base_prompt: str, candidate_ir: dict[str, Any], score_report: dict[str, Any]) -> str`
   - 將上一輪合法但分數未達標的 `candidate_ir` 摘要、`score_report["penalties"]` 與 `score_report["suggestions"]` 組合成繁體中文任務級遞迴精煉提示詞，要求模型在維持 `validate_ir` 合規的前提下針對弱點重新生成。
6. `record_review_lesson(rejected_ir: dict[str, Any], approved_ir: dict[str, Any], *, topic_key: str, title: str = "", path: Optional[Path] = None) -> Optional[dict[str, Any]]`
   - 比對被替換的 V1 (`rejected_ir`) 與獲選的 V2 (`approved_ir`)，若兩者在第一幕 `blueprint`、或 `keywords` / `step_labels` 有實質差異，自動提煉一條治理教訓寫入 `path`（預設為 `data/visual/harness_lessons.json`，支援測試傳入 `tmp_path`），同 `lesson_id` 採冪等更新。

### 3.3 `src/visual/autodraft.py` 任務級遞迴整合
- 在 `parse_and_build_tree_ir()` 中補齊 `pathology_mechanism` 於 `valid_scene1_blueprints` 的支援與參數塑形（`organ_system`、`lesion_label`、`mechanism_label`、`layer_labels`、`step_labels`），使 `autodraft` 亦能原生生成基層專科器官病理藍圖。
- 在 `build_tree_visual_prompt(tree, template_override=None)` 結尾注入 `format_lessons_for_prompt(select_lessons_for_tree(tree))`。
- 在 `autodraft_from_tree()` 新增參數：
  - `k_candidates: int = 1`
  - `recursion_mode: str = "sequential"`（支援 `"sequential"` 與 `"parallel"`）
- 當 `k_candidates == 1` 時，維持既有單次生成＋自癒重試行為（100% 向後相容，且額外在 `metadata` 附帶 `harness_score`）。
- 當 `k_candidates > 1` 時：
  - **`sequential` 模式**：先產生第 1 個通過 `validate_ir` 的候選 IR 並以 `score_visual_ir_alignment(tree, ir)` 評分；若分數 `< 0.88` 且尚未達 `k_candidates` 上限，以 `build_alignment_critique_prompt()` 驅動下一輪精煉生成，保留所有合法候選中 `score` 最高者寫入資料庫。
  - **`parallel` 模式**：獨立執行最多 `k_candidates` 次生成，對所有通過 `validate_ir` 的候選評分，取最高分者寫入資料庫。

## 4. 驗證與測試標準 (Verification Criteria)
1. 單元與整合測試 `tests/test_harness_optimizer.py` 全數通過：
   - 驗證 `load_harness_lessons` 與 `select_lessons_for_tree` 對媽咪改造、FUE 植髮、呼吸道感冒、三高慢性病等主題能精準命中對應教訓。
   - 驗證 `score_visual_ir_alignment` 能對含錯置詞彙（如媽咪改造出現「闊頸肌」）或罐頭標籤（如「重要標籤一」）的 IR 顯著扣分並給出具體建議，而對專一性高的 IR 給出高分（`>= 0.85`）。
   - 驗證 `autodraft_from_tree(..., k_candidates=3, recursion_mode="sequential")` 在模擬 LLM 先回傳罐頭低分合法 IR、收到 Critique 後回傳高專一性 IR 時，能自動選中最高分候選並記錄 `harness_score` 與 `harness_k`。
   - 驗證 `adopt_v2_candidate` 或 `record_review_lesson` 能將 V1/V2 差異寫入隔離的 `lessons.json`。
2. 執行 `bash scripts/harness_check.sh`，確保靜態安全掃描、瀏覽器渲染、ICD-10 基層疾病、Autodraft 與 Harness² 測試 100% 通過。
