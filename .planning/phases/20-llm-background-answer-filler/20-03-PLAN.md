## 3. Claude 對抗性審查與加固（指派 Claude 5.5 Sonnet）
審查全部改動，重點檢查：
1. **執行緒安全與單例鎖**：
   - 確認 `batch_answer_job` 在啟動、狀態查詢、取消與中斷時無 Race Condition。
   - 確認與單題 LLM 生成共享 `_GENERATION_LOCK`，防範雙重併發打爆 GPU 顯存。
2. **輪詢安全與 DoS 防護**：
   - 狀態端點 `status` 必須極度輕量（純記憶體快照讀取，不執行重量 SQL 查詢），防範前端高頻輪詢造成伺服器負載過高。
3. **例外復原與優雅降級**：
   - 當本地 LLM 離線（llama-server 斷線）時，背景 Worker 必須優雅標記 `aborted` 並釋放鎖，絕不能卡死或洩漏未關閉連線。
4. **規範文檔同步**：
   - 更新 `AGENTS.md`，新增「2.19 背景衛教答案自動生成器與離峰排程（Phase 20 新增）」章節。
5. **加固測試**：`tests/test_phase20_hardening.py`。
