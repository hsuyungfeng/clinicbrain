# Plan 20-01: 後端自動補齊端點與夜間批次調度擴充

## 1. 目標
在 `src/api/routes/admin.py` 中新增自動撈取並排程所有未補齊草稿的端點，並在 `src/batch/runner.py` 夜間批次中整合自動填補答案能力。

## 2. 實作任務（指派 Agy 3.6 Flash）
1. 擴充 `src/pageindex/batch_answer_job.py`:
   - 新增 `get_pending_unanswered_ids(conn, clinic_id: str | None = None, limit: int = 100) -> list[int]`:
     - 查詢所有 `review_status='pending'` 且 `(answer IS NULL OR length(trim(answer)) < 15)` 的列 ID。
     - 依建立時間排序，優先處理較早的題目。
2. 擴充 `src/api/routes/admin.py`:
   - 新增 `POST /api/v1/admin/review/autofill/all`:
     - 自動呼叫 `get_pending_unanswered_ids()` 取得待補齊 ID（上限 100 筆）。
     - 呼叫 `batch_answer_job.start()` 啟動背景 Worker。
     - 若無任何待補齊題目，回傳 `{"status": "noop", "message": "目前無待補齊答案之草稿"}`。
     - 若目前已有任務在執行，回傳 HTTP 409。
3. 擴充 `src/batch/runner.py`（夜間離峰批次調度器）:
   - `BatchConfig` 新增 `enable_autofill_answers: bool = True`。
   - `BatchSummary` 新增 `autofill_answers_count: int = 0`。
   - 於批次前置步驟中，自動掃描並以既有 `_local_llm_call` 批次補齊未回答之 pending 題目。
4. 撰寫單元與整合測試 `tests/test_autofill_backend.py`:
   - 驗證 `autofill/all` 自動排入待補齊題目。
   - 驗證無待補題目時的 `noop` 回應。
   - 驗證重複啟動時的 409 衝突防護。

## 3. 驗收標準
- `pytest tests/test_autofill_backend.py` 全部通過。
