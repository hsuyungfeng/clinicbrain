# Plan 20-02: Web App 前端「一鍵背景自動補齊」按鈕、進度條與輪詢介面

## 1. 目標
在 Web App（`src/web/static/`）待審清單頂部與浮動操作列加入自動補齊按鈕，並建置即時進度橫幅（Progress Banner），每 3 秒自動輪詢狀態，提供流暢的非同步作業體驗。

## 2. 實作任務（指派 Agy 3.6 Flash）
1. 介面結構擴充 (`index.html`):
   - 待審清單頂部新增按鈕：
     - **【🚀 一鍵背景自動補齊所有答案】** (`btnAutoFillAll`)。
   - 頂部增設動態進度橫幅 (`autofillProgressBanner`，預設 hidden)：
     - 包含標題、狀態徽章（執行中/已取消/已完成）、進度條百分比（`<div class="progress-bar">`）。
     - 顯示文字：*「AI 背景補齊中：已完成 X / Y 題 (Z%) | 目前處理 ID: #...」*。
     - 附帶【⏹️ 中止作業】按鈕 (`btnCancelAutoFill`)。
   - 底部浮動操作列（Sticky Action Bar）新增按鈕：
     - **【🤖 批量生成所選答案 (N)】** (`btnBatchGenerateSelected`)。
2. 前端互動與輪詢邏輯 (`app.js`):
   - 點擊【🚀 一鍵背景自動補齊所有答案】：
     - 發出 `POST /api/v1/admin/review/autofill/all`。
     - 若成功啟動，展開進度橫幅並啟動定時器（每 3 秒輪詢一次 `GET /api/v1/admin/review/batch-generate/status`）。
   - 點擊【🤖 批量生成所選答案】：
     - 發出 `POST /api/v1/admin/review/batch-generate`（傳入選取的 `faq_ids`）。
     - 同樣展開進度橫幅並啟動輪詢。
   - 輪詢回調處理：
     - 依據 `status.snapshot` 更新進度條長度與統計文字。
     - 當狀態轉為 `done` 或 `aborted` 或 `cancelled` 時：停止輪詢、提示完成、自動重新整理待審卡片與儀表板統計。
   - 頁面載入時主動檢查一次狀態：若伺服器本來就在背景執行作業，自動恢復顯示進度橫幅與輪詢。
3. 樣式美化 (`style.css`):
   - 為進度橫幅與進度條增設現代青綠色彩（Gradient Progress Animation）。
4. 前端測試擴充 `tests/test_web_ui_v3.py`:
   - 驗證 HTML 中包含 `btnAutoFillAll`、`autofillProgressBanner` 與 `btnCancelAutoFill` 結構。
   - 驗證 JS 中綁定了輪詢與進度處理邏輯。

## 3. 驗收標準
- 點擊一鍵補齊後前端不阻塞，進度條動態更新，完成後卡片標籤自動更新。
