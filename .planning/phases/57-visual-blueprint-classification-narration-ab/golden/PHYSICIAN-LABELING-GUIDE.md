# 黃金標準集標註說明（給審閱醫師）

本說明對應 `golden_set_template.csv`，共 50 筆。目的是為「動畫第一幕藍圖分類器」建立醫師標準答案，
用來評估分類器的準確率。**醫師的判斷是此評估的基準，請依臨床專業判斷填寫，不必迎合系統現行的推斷結果。**

---

## 一、你需要填的兩個欄位

| 欄位 | 說明 | 填寫方式 |
| :--- | :--- | :--- |
| `physician_blueprint` | 你認為此主題第一幕最適合的動畫藍圖 | 只能從下方「藍圖選項」中**擇一**，拼字須完全一致 |
| `evidence_span` | 支持你選擇的**原文片段** | 必須是來源衛教文字中實際出現的連續文字，建議 10 至 40 字 |

**不確定時**：`physician_blueprint` 請填 `other`，`evidence_span` 留空。**不要為了填滿而勉強選擇。**
`other` 是正確答案之一，代表「現有藍圖都不適合」。

---

## 二、藍圖選項（共 12 個 + other）

下表描述取自系統的藍圖規格（`src/visual/blueprints.py` 的預設值與 `src/visual/autodraft_ir.py` 的參數整形器），
說明的是**該動畫藍圖呈現什麼**。臨床用語的正確性由醫師確認。

| 藍圖代碼 | 動畫呈現的內容 | 適合的主題類型 |
| :--- | :--- | :--- |
| `pathology_mechanism` | 致病因子刺激 → 局部組織發炎 → 屏障逐步修復。依器官系統分為 15 類（呼吸道、心血管代謝、消化道、皮膚屏障、關節脊椎、泌尿骨盆、牙科口腔、中醫經絡、內分泌、眼底視網膜、前眼、耳鼻喉、泌尿生殖、牙周、中醫針灸） | 以發炎、感染、受損等**疾病機轉**為主的主題 |
| `process_diagram` | 來源 → 2 至 4 層容器 → 三步驟流程的通用流程圖 | 無特定器械、器官或手術動作，只需說明流程或概念的主題 |
| `skin_energy` | 聚焦探頭將能量送入皮膚各層（表皮、真皮膠原、筋膜），產生深層熱凝結並促進膠原收縮。模式為聚焦或容積式 | 以**能量裝置作用於皮膚／皮下組織**為主的療程 |
| `laser_action` | 光束照射色素團塊或組織，以碎裂色素或分段式微熱區作用於表皮與真皮 | 以**雷射或光能**作用為主的療程 |
| `neuromuscular` | 神經末梢 → 過度收縮的肌肉 → 表面動態皺紋；注射物調節神經訊號使肌肉放鬆 | 以**神經肌肉作用的注射治療**為主的主題 |
| `dermal_support` | 填充凝膠依表皮輪廓層與真皮皮下層分層注入，支撐凹陷部位 | 以**填充物注射、補充容積**為主的主題 |
| `cyst_excision` | 微創切口後，減壓排空、完整剝離囊袋 | 以**囊腫或粉瘤**的切除或剝離為主的主題 |
| `nail_matrix` | 嵌甲邊緣游離、側切移除、甲床基質重整 | 以**指甲或甲床**相關處置為主的主題（如嵌甲） |
| `subdermal_curettage` | 微創切口入路，旋轉刀刮除皮下組織，同時負壓抽吸 | 以**皮下組織微創刮除**為主的主題 |
| `deep_plane_facelift` | 微創解離韌帶，於骨膜處錨定並向上提拉 SMAS 筋膜層，表皮無張力縫合 | 以**臉部深層平面拉提**為主的主題 |
| `corset_platysmaplasty` | 微創修整脂肪，對縫兩側闊頸肌，形成頸部緊緻的束帶效果 | 以**頸部闊頸肌或頸部輪廓**為主的主題 |
| `surgical_action` | 切口進入、保護神經、截骨或骨骼位移、鈦板釘固定。解剖目標分為下顎、SMAS 臉部、頸部闊頸肌、顴骨、下巴、一般外科 6 類 | 以**截骨、骨骼固定、需保護神經**的手術為主的主題 |
| `other` | 以上皆不適合 | 見第三節 |

> 分類器提示詞已依本表更新（`blueprint_classifier.py` 規則 1 至 8），涵蓋全部 12 個藍圖。

## 三、填寫原則

1. **依來源原文判斷，不依標題猜測。** 主題名稱相近不代表藍圖相同（例如同為雷射療程，若作用對象是色素用 `laser_action`；
   若是手術切除則應看是否為囊腫或嵌甲）。
2. **只有一個答案。** 若主題同時涉及兩類，請選對第一幕最重要的一類；其他情況寫在備註。
3. **`evidence_span` 要能在原文中找到。** 請直接複製原文，不要改寫、不要加標點、不要翻譯。
4. **不要參考系統目前的 `current_inferred_blueprint`。** 該欄位是現行規則的推斷，作為對照用，請勿以它為答案。
5. **原文不足以判斷時**（內容過少、過於籠統、或與上表所有藍圖都不符），請填 `other` 並在備註說明。
6. **`process_diagram` 是通用流程圖，不是預設答案。** 若原文有明確的機轉、器械或手術動作，應優先選擇對應藍圖。

## 五、交回方式

1. 直接在 `golden_set_template.csv` 的 `physician_blueprint` 與 `evidence_span` 欄位填寫。
2. 完成後通知專案團隊。團隊會以程式檢查：
   - `physician_blueprint` 是否為合法選項；
   - `evidence_span` 是否確為來源原文子字串（忽略空白與全半形標點的差異）。
3. 檢查未通過的列，會退回請醫師確認，不會自動修改您的答案。
