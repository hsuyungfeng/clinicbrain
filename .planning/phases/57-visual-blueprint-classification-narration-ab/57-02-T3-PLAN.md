# 57-02 T3 計畫：黃金標準集準確率評估（Planner: Claude / Executor: agy）

## 目標
以醫師標註（`golden/physician_labeling_sheet.xlsx` 的「標註」工作表，已通過 `--require-complete`）為標準答案，
評估第一幕藍圖分類器的準確率，產出 `57-02-EVAL.md`，並與 57-01 基線比較。

## 輸入
- `golden/physician_labeling_sheet.xlsx`
  - 「標註」：`doc_id`、`source_text`、`physician_blueprint`（標準答案）、`evidence_span`。
  - 「AI建議（僅供參考）」：`ai_suggested_blueprint`、`ai_status`、`ai_confidence`、`ai_evidence_span`。
    AI 建議由同一分類器（`classify_scene1_blueprint` + 本地 LLM）產生，作為分類器預測值使用，不重跑 LLM。
- `golden/baseline_metrics.json`（57-01 基線，目前 `accuracy: null`；評估後需補上 `rule_engine` 的對照數字，或於 EVAL 內引用其藍圖分布）。

## 決策（已定案，執行時照做）
1. **預測值來源**：使用「AI建議」工作表的 `ai_suggested_blueprint`。不重跑 LLM，確保結果可重現。
2. **有效判定**：`ai_status == "ok"` 的預測才算「自動接受」。其他狀態（`invalid_evidence`、`needs_review`）
   另行統計，不混入準確率的分子。
3. **兩種準確率都要報告**：
   - A. 原始準確率：預測藍圖 == 醫師藍圖（所有 50 筆，含 `needs_review`／`invalid_evidence`）。
   - B. 自動接受準確率：僅 `ai_status == ok` 的列；並列出自動接受率（ok 筆數 / 50）。
4. **類別**：12 個藍圖 + `other`，共 13 類。
   - 每類召回率 = 該類中預測正確的列數 / 醫師標為該類的列數（分母為 0 時標 N/A）。
   - 混淆矩陣：列為醫師標準答案，欄為預測值（含 `other`）。
   - `other` 比例：醫師 `other` 數與預測 `other` 數分別列出。
   - `invalid_evidence` 比例：列出筆數與 doc_id。
5. **錨定效應檢查**：醫師標註時可能參考了 AI 建議。若能判斷，需分開報告
   「醫師與 AI 建議一致」與「不一致」兩組的筆數；此項僅為描述性統計，不作為準確率結論。
   注意：此檢查只能說明一致率，無法證明醫師是否受影響。
6. **門檻**：`85%` 為 agy 於 57-SUMMARY 中提出，**尚未經使用者確認**。腳本以參數 `--threshold` 接受，
   預設 0.85，但 EVAL 中必須標註「門檻未經確認」，且不得據此自動切換 `--blueprint-mode`（57-02 硬性限制）。
7. **不得**修改「標註」或「AI建議」工作表，不得寫入 `clinic.db`。

## 產出
- `scripts/eval_blueprint_classifier.py`
  - CLI：`--sheet <xlsx>`（預設為上述路徑）、`--threshold 0.85`、`--out <md 路徑>`。
  - 純函式核心 `evaluate(rows) -> dict`，可被測試；CLI 負責讀檔與寫 EVAL。
  - 退出碼：0 = 評估完成；1 = 有未標註列（拒絕評估）；2 = 讀檔或欄位錯誤。
- `tests/test_eval_blueprint_classifier.py`：至少覆蓋
  - 全部正確 → 準確率 1.0；全部錯誤 → 0.0；
  - `invalid_evidence` 與 `needs_review` 不計入 B 的分子；
  - 分母為 0 的類別顯示 N/A 而非除以零；
  - 未標註列導致退出碼 1；
  - 欄位缺失導致退出碼 2。
- `golden/57-02-EVAL.md`：由腳本產生，內容含 A、B 兩種準確率、各類召回率、混淆矩陣、
  `other` 與 `invalid_evidence` 比例、錨定效應描述、門檻狀態聲明。
- 執行總結：`57-02-T3-SUMMARY.md`（列出指令、測試結果、與驗收條件的逐項對照）。

## 威脅與限制
| 風險 | 緩解 |
|---|---|
| 把 AI 建議誤當醫師答案 | 只讀「標註」欄位作為標準答案；腳本測試覆蓋此點 |
| 樣本只有 50 筆，準確率波動大 | EVAL 需附 50 筆的分子分母，不只給百分比 |
| 評估輸入與正式流程不同（source_text vs 項目資料+事實卡） | EVAL 明確聲明此差異，列為限制 |
| 門檻未經確認 | 以參數傳入並在 EVAL 標示未確認 |
