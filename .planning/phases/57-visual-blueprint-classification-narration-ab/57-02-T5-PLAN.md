## 二、實作內容

1. **`TOPIC_BLUEPRINT_REGISTRY`**（`src/visual/blueprint_registry.py`）
   - 有序列表，每項為 `(觸發關鍵字清單, blueprint)`，採第一個命中者。
   - 依決定 A–C 建立，例如：粉瘤／囊腫→`cyst_excision`；嵌甲→`nail_matrix`；狐臭／頂漿腺／脂肪瘤→`subdermal_curettage`；
     SMAS／深層平面拉提→`deep_plane_facelift`；電波／音波／微針→`skin_energy`；雷射／皮秒／飛梭／光纖→`laser_action`；
     海菲秀／水光→`process_diagram`；感冒／上呼吸道感染／咽炎／過敏性鼻炎／胃炎→`pathology_mechanism`。
   - 函式 `lookup_blueprint(title, icd_name) -> Optional[str]`：無命中回傳 `None`，交由 LLM 分類器處理。
2. **特徵詞錨定（證據檢驗）**：`classify_scene1_blueprint` 的結果若選了某藍圖，其 `evidence_span` 必須含該藍圖的特徵詞之一，
   否則判為 `invalid_evidence`。特徵詞表放在同一個 registry 檔案中。
3. **放行閘門（複合條件）**：分類結果只有在以下任一條件下才可標記為可自動接受：
   - 命中查表（`source = "registry"`）；或
   - LLM 結果 `status == ok` 且通過特徵詞錨定。
   **不採用信心門檻 0.85**（已驗證無效）。
4. **過渡期規則**：`--blueprint-mode classifier` 的路徑中，即使結果可自動接受，也一律標記 `needs_review: true` 並跳過入庫，
   只寫離線 JSON 產物供審閱。`fixed` 路徑不受影響。
5. **不得**變更 `TOPIC_BLUEPRINT_REGISTRY` 以外的 `fixed` 行為。
