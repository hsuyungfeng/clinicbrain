# Plan 16-03: Systemd 定時器單元、晨間審核通報與端到端排程驗收

## 一、 目的與任務目標
提供運維等級的 Linux 系統排程守護，並建立專為醫師設計的晨間審核通報工具：
1. **Systemd 定時器與服務單元**：
   - `templates/systemd/clinicbrain-nightly.service`：定義夜間批次執行命令、工作目錄、日誌輸出與環境變數。
   - `templates/systemd/clinicbrain-nightly.timer`：定義排程觸發時間（`OnCalendar=*-*-* 03:00:00`，`Persistent=true`）。
   - 包含一鍵安裝/部署腳本說明與 crontab 備用方案。
2. **晨間醫師審核通報工具 (`scripts/review_faq.py pending-summary`)**：
   - 擴充 `scripts/review_faq.py`，新增 `pending-summary` 命令。
   - 輸出美觀繁體中文摘要：
     - 待簽核衛教草稿總數。
     - 各標的疾病（如「濕疹」、「急性咽喉炎」）及各自參考病歷筆數。
     - 提供快速一鍵批次簽核指令指引（例如 `python3 scripts/review_faq.py approve --all-pending` 或逐筆審核）。
3. **全系統整合驗收測試**：
   - `tests/test_nightly_full_schedule_e2e.py`：模擬「夜間定時器觸發 ➔ 批次提煉 ➔ 產生 pending 草稿 ➔ 晨間 pending-summary 檢視 ➔ 醫師簽核 ➔ 查詢端點命中」全流程閉環。

## 二、 驗證標準
- 端到端整合測試全數 PASS。
- 正式庫 `clinic.db` SHA-256 不變性驗證。
