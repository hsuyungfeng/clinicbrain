# Plan 16-01: 夜間批次擴充與 SOAP 提煉子任務整合

## 一、 目的與任務目標
擴充既有夜間批次核心引擎（`src/batch/runner.py` 與 `src/batch/run_log.py`）及 CLI 命令列工具（`scripts/run_nightly_batch.py`），使夜間批次能夠自動調度執行 SOAP 臨床居家照護提煉：
1. `BatchConfig` 新增欄位：
   - `enable_soap_distill: bool = True`
   - `soap_clinic_id: str = "3503190424"`
   - `soap_min_occurrences: int = 2`
   - `soap_only: bool = False`
2. `BatchSummary` 新增統計欄位：
   - `soap_distilled_count: int = 0`
   - `soap_conditions: List[str] = field(default_factory=list)`
3. `run_batch()` 執行流程整合：
   - 在執行 LLM 生成前，先呼叫 `distill_soap_records(conn, clinic_id, min_occurrences, dry_run)`。
   - 記錄提煉結果至 `logger` 與 `summary`。
   - 若 `soap_only=True`，則跳過 LLM FAQ 生成與推理樹重建。
4. CLI 參數擴充：
   - `--skip-soap`：略過 SOAP 提煉任務。
   - `--soap-only`：僅執行 SOAP 提煉任務。
   - `--soap-clinic-id`：指定提煉之診所機構代碼。
   - `--soap-min-occurrences`：指定居家照護出現頻率門檻（預設 2）。

## 二、 驗證標準
- 單元測試：`tests/test_nightly_soap_batch.py` 驗證：
  1. `run_batch()` 預設執行 SOAP 提煉並回報正確之 `BatchSummary`。
  2. `--skip-soap` 與 `--soap-only` 旗標正確生效。
  3. `--dry-run` 模式下連線為唯讀，不產生資料庫寫入。
