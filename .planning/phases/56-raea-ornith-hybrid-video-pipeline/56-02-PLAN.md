<task type="auto">
  <name>Task 2: 實作 src/visual/raea_pipeline.py 與批次 CLI scripts/run_raea_reel_batch.py</name>
  <files>
    clinicbrain/src/visual/raea_pipeline.py
    clinicbrain/scripts/run_raea_reel_batch.py

  <action>
    1. 在 `src/visual/raea_pipeline.py` 實作：
       - `is_raea_available() -> bool`：檢查 `raea`（含 `~/.local/bin` / `~/.raea/bin`）是否可用。
       - `prepare_bevy_glb(src_glb: Path, dst_glb: Path) -> Path`：檢查或透過 `npx --yes @gltf-transform/cli` 依序執行 `copy` 與 `dequantize`，產生無 `EXT_meshopt_compression` / `KHR_mesh_quantization` 的 Bevy 相容 GLB。
       - `run_raea_check(mp4_path: Path, manifest_path: Path | None = None) -> dict`：執行 `raea check` 並解析通過狀態與錯誤/警告清單，作為強制品管閘門。
       - `render_reel_with_raea(conn, topic_key, output_dir=None, use_llm=True, quality="high", max_sec=None, force=False) -> dict`：
         * 檢查 `data/videos/{topic_key}_portrait.mp4` 存在（若缺則報錯提示先跑 `video_queue`）。
         * 呼叫 `generate_reel_script(conn, topic_key, use_llm=use_llm)` 取得結構化文案。
         * 計算 SHA-256 快取鍵（母片雜湊 + 腳本雜湊 + 模板雜湊），已存在且相符時跳過重複渲染。
         * 於獨立暫存工作目錄複製模板與素材、生成背景音軌（或讀取指定音訊）、呼叫 `raea render --quality {quality} --manifest ...` 與 `raea check`。
         * `raea check` 通過後，原子搬移成品至 `data/videos/reels/{topic_key}_reel.mp4` 並寫入 `.meta.json`。
       - `render_3d_with_raea(core_glb, overlay_glb, out_mp4, title, subtitle, quality="master", ...) -> dict`：封裝 3D 解剖運鏡渲染流程與 `raea check` 驗證。
    2. 建立 `scripts/run_raea_reel_batch.py`：
       - 提供 `--topic-key`、`--all`、`--limit`（預設 5）、`--skip-llm`、`--max-sec`、`--quality`（`draft|high|master`，預設 `high`）、`--force`、`--dry-run`。
  </action>
