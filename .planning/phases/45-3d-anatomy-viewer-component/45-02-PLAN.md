# 45-02-PLAN: PageIndex 臨床推理樹關聯契約、事件匯流排與法規防線

## 1. 目標 (Objective)
建立 Python 後端結構化解剖目錄 `src/visual/anatomy_catalog.py`，定義 PageIndex 療程（`doc_id`）與 3D 解剖模型／層次步驟之關聯契約；在 FastAPI 新增相關端點；在前端建立事件匯流排（Event Bus）雙向協定，並實施嚴格價格遮蔽（`deep_mask_prices`）與法定免責聲明檢驗。

## 2. 交付成果 (Deliverables)
1. **後端資料契約 (`src/visual/anatomy_catalog.py`)**：
   - 提供 `ANATOMY_CATALOG` 字典，涵蓋醫美整形與專科常見項目（如 `hifu-lifting`, `blepharoplasty`, `rhinoplasty`, `dental-implant` 等）。
   - 提供 `get_anatomy_metadata(doc_id: str) -> dict | None` 查詢函式。
   - 所有標籤文字均經過繁體中文校準與 `deep_mask_prices()` 安全過濾。
2. **FastAPI 服務端點 (`src/api/routes/visual.py` 或獨立解剖端點)**：
   - 新增 `GET /api/v1/visual/anatomy/{doc_id}`，回傳該療程結構化解剖定位與步驟清單。
   - 包含常駐免責聲明字串與模型靜態路徑。
3. **前端事件匯流排協定**：
   - 支援 `window.addEventListener('anatomy:focus-step', ...)`。
   - 點擊臨床推理樹四段式步驟（`pre_op`, `procedure`, `post_op_short`, `maintenance`）時發送事件，`<clinic-anatomy-viewer>` 接收後觸發運鏡與層次高亮。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] `src/visual/anatomy_catalog.py` 完整定義並通過單元測試。
- [ ] API 端點 `GET /api/v1/visual/anatomy/{doc_id}` 正常回傳，價格數字 100% 遮蔽。
- [ ] 事件 `anatomy:focus-step` 正確驅動檢視器更新。
