# 45-01-PLAN: 3D 解剖資產配置與 <clinic-anatomy-viewer> Web Component 核心渲染器實裝

## 1. 目標 (Objective)
建立本地 3D 解剖靜態資產目錄，打包輕量 Three.js 核心庫與專科網格模型（< 3MB）；以原生 Web Component 實作 `<clinic-anatomy-viewer>` 核心渲染器，支援延遲載入、相機平滑運鏡、網格分層聚焦高亮、WebGL 上下文丟失自癒機制與確定性 2D 降級備援介面。

## 2. 交付成果 (Deliverables)
1. **靜態資產與本地託管 (`src/web/static/anatomy/`)**：
   - 複製並最佳化本地 Three.js 核心與 GLTFLoader 腳本。
   - 納入專科解剖 3D 網格模型（如頜面/神經血管模型 `context.glb` 與 `neurovascular.glb`，體積嚴格受控於 3MB 內）。
2. **Web Component 實作 (`src/web/static/anatomy_viewer.js`)**：
   - 定義 Custom Element `<clinic-anatomy-viewer>`，具備 Shadow DOM 樣式隔離。
   - 支援屬性 `model-src`、`metadata-src`、`auto-rotate`、`fallback-2d`。
   - 實現平滑相機導航（Ease-out 緩動飛向指定座標與角度）。
   - 實現網格高亮機制（Highlight Layer / Warning Zone 脈衝發光）。
   - 上下文丟失監聽（`webglcontextlost` / `webglcontextrestored`）。
   - 浮動解說 Tooltip 與常駐法定免責聲明。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] `<clinic-anatomy-viewer>` 自定義元素成功註冊，Shadow DOM 正確建立。
- [ ] 3D 網格檔案能自本地 `src/web/static/anatomy/` 離線正常載入，零外部網路請求。
- [ ] 相機運鏡與高亮動畫運作正常，支援手勢/滑鼠軌道控制（OrbitControls）。
- [ ] 支援 WebGL context loss 偵測與 2D 降級備援觸發。
