# 45-03-PLAN: 前端 Web 整合、2D 確定性降級防線與 Hermes 獨立測試驗收

## 1. 目標 (Objective)
將 `<clinic-anatomy-viewer>` 整合入 Web 後台（`index.html`）與諮詢頁面（`consult.html`）；實裝當 WebGL 不支援、崩潰或用戶手動切換時之確定性 2D 向量動畫降級防線；編寫自動化測試，並透過 `herdr` 調度待命中的獨立 Agent Hermes (`wA:p3`) 作為外部 Tester 進行完整驗收。

## 2. 交付成果 (Deliverables)
1. **Web 介面整合 (`src/web/static/index.html`, `app.js`, `consult.html`, `consult.js`)**：
   - 增加「3D 解剖視角」切換按鈕，支援在 3D WebGL 模型與 2D 向量動畫之間流暢切換。
   - 支援點選 PageIndex 樹狀步驟直接聯動解剖視角。
2. **2D 向量降級防線 (Fallback Mechanism)**：
   - 當檢測到 WebGL 不受支援、`webglcontextlost` 超時無法恢復、或屬性標記 `force-fallback="true"` 時，自動將渲染容器轉化為 `<canvas id="vector-fallback-canvas">` 並呼叫 `visual_engine.js` 播放確定性 2D 向量解說卡。
3. **自動化驗證測試 (`tests/test_anatomy_viewer.py`)**：
   - 測試目錄元資料、API 端點、價格遮蔽、繁體中文合規與降級防線邏輯。
4. **Hermes 獨立驗收 (Herdr Subtask)**：
   - 使用 `herdr agent prompt wA:p3` 派遣獨立驗證任務。
   - Hermes 獨立審計代碼、運行測試套件、檢查 WebGL/2D 降級邏輯與醫療法規合規，產出正式驗收報告。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] 前端頁面可成功嵌入 `<clinic-anatomy-viewer>`，無樣式與控制衝突。
- [ ] 2D 降級備援機制運作無誤（WebGL 停用或模擬 context loss 時自動展示 2D 向量動畫）。
- [ ] 所有單元測試與端點測試 100% 通過。
- [ ] Hermes (`wA:p3`) 執行獨立驗證並簽署正式驗收報告。
