# Plan 22-01: FTS5 BM25 相關度排序與多詞交集評分

## 1. 目標
升級 `src/query/search.py` 與 `src/query/router.py` 的全文檢索能力。在 `search_text` 中引入 FTS5 BM25 評分排序（`ORDER BY _fts.rank ASC`），並在多關鍵字檢索聚合（`_search_terms_merged`）中加入多詞命中加權與穩定排序，確保自然語言查詢（如「甲溝炎要怎麼照護？」）能優先召回同時符合主疾病與修飾意圖之高相關度問答。

## 2. 實作任務（指派 Agy 3.6 Flash）
1. **升級 `src/query/search.py:search_text`**：
   - 當走 FTS5 分流（`_use_fts(query) is True`）時，將原 `rowid IN (SELECT rowid ...)` 升級為 subquery JOIN 語法：
     ```sql
     SELECT {', '.join([f'{table}.{c}' for c in select_columns])}
     FROM {table}
     JOIN (
         SELECT rowid, rank FROM {fts_table} WHERE {fts_table} MATCH ?
     ) AS _fts ON {table}.rowid = _fts.rowid
     {where_clause}
     ORDER BY _fts.rank ASC
     LIMIT ?
     ```
   - 確保 `extra_where` 欄位過濾（如 `clinic_id`、`category`、`review_status` 等）在 JOIN 架構下依然無歧義解析並正確生效。
   - 保留少於 3 字之 LIKE fallback 查詢行為不變。
2. **優化 `src/query/router.py:_search_terms_merged`**：
   - 改善多詞迴圈提前中斷問題：不要在第一個詞湊滿 `limit` 時就立即丟棄後續詞彙。
   - 收集所有詞彙之候選結果（各詞上限設為 `cand_limit = max(limit, 20)`）。
   - 引入多詞命中加權排序（Multi-Term Intersection Boost）：
     - 同時命中越多搜尋詞的問答（例如同時命中「甲溝炎」與「照護」之 FAQ），優先權最高。
     - 次之按各檢索器之原始相關度排序。
     - 最後截斷至請求之 `limit` 筆數回傳。
3. **單元測試驗證 `tests/test_rag_bm25_retrieval.py`**：
   - 測試 BM25 排序生效：驗證高詞頻與語意貼近之 FAQ 排在較早期無關 FAQ 前面。
   - 測試多詞交集加權：驗證「甲溝炎要怎麼照護？」能精準將包含居家照護的 FAQ（如 ID 497 等）排進 Top 5。
   - 驗證 `search_drugs`、`search_service_items`、`search_page_index_trees`、`search_faq_cache` 均相容通過。

## 3. 驗收標準
