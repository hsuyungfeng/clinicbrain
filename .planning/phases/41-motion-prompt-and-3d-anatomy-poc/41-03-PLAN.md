# 41-03-PLAN: 3D 臨床解剖檢視器前端組件架構與 PageIndex 關聯設計

## 1. 目標 (Objective)
依據 PoC 評估結論，設計 3D 臨床解剖檢視器（Consultation 3D Viewer）的前端組件架構與 PageIndex 臨床推理樹關聯契約，制定病患諮詢端點與後台審核頁面中「點選療程／疾病 ➔ 自動連動 3D 視角旋轉、層次剝離與病灶高亮」的標準資料介面與醫療法規防線。

## 2. 交付成果 (Deliverables)
1. **3D 臨床解剖檢視器架構設計規格書 (`docs/anatomy-3d-architecture.md`)**：
   - **組件邊界與渲染生命週期**：設計輕量化 Web Component (`<clinic-anatomy-viewer>`) 或受限 Canvas 前端播放器，支援延遲載入（Lazy Loading）、進度骨架屏、WebGL 上下文丟失自癒與行動端觸控手勢（旋轉/平移/縮放）。
   - **PageIndex 臨床推理樹關聯契約**：
     - 定義 `page_index_trees` 之 `anatomy_metadata` 擴充規格或映射清單：
       ```json
       {
         "doc_id": "hifu-lifting",
         "anatomy_target": "facial_smas",
         "default_view": {"pitch": 15, "yaw": -30, "zoom": 1.2},
         "highlight_layers": ["epidermis", "dermis", "subcutaneous_fat", "smas"],
         "dissect_level": 3
       }
       ```
     - 支援病患諮詢或醫師點擊特定章節（如 `procedure` 深度或 `pre_op` 風險提示）時，透過事件匯流排（Event Bus）驅動 3D 模型平滑過渡至指定視角與高亮部位。
2. **多層醫療法規與隱私安全規範**：
   - **零價格外洩防線**：3D 解剖標籤、附屬提示窗與動態說明一律串接 `deep_mask_prices()`，嚴禁夾帶價格數字。
   - **無保證療效與免責聲明**：所有解剖可視化展示底部均強制附帶「解剖結構存在個人體質差異，實際手術計畫以醫師親自門診評估為準」法定免責字樣。
   - **全正體中文專用**：所有 3D 部位標籤與互動文字強制使用台灣標準醫學名詞。
3. **後續階段導入路徑與驗收條件 (Milestone Gate)**：
   - 制定未來進入正式實作階段的具體準則（模型優化壓縮門檻、專科網格精細度簽核與跨平台相容性指標）。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] 完成 `docs/anatomy-3d-architecture.md` 架構設計文件，包含組件生命週期、PageIndex 關聯結構與事件流通圖。
- [ ] 明確定義價格清洗、免責標籤與繁體名詞等法規防禦邊界。
- [ ] 獲得專案技術與臨床審核標準對齊，為後續 3D 模組實作奠定完整規範。
