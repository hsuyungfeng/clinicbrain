# 41-02-PLAN: FreedomIntelligence/BodyVista 沙盒概念驗證（PoC）與專科精細度評估

## 1. 目標 (Objective)
在隔離沙盒環境檢驗香港中文大學（深圳）開源之 3D 互動解剖平台 `FreedomIntelligence/BodyVista`，實測其 3D WebGL 模型體積、渲染效能與模組依賴，並針對緻妍外科診所（`3503190424`）核心醫美與整形外科療程進行解剖精細度抽查與在地化合規審計。

## 2. 交付成果 (Deliverables)
1. **沙盒環境檢測與資產結構分析**：
   - 於沙盒路徑檢測 BodyVista 原始碼庫結構。
   - 盤點 3D 網格模型（GLTF/GLB/OBJ）、紋理貼圖（Textures）之總檔案大小、單一模型體積分佈與載入記憶體開銷。
   - 評估在診所內網平板或桌面端瀏覽器中運行 60fps WebGL 之硬體預算門檻。
2. **核心專科解剖精細度抽查報告 (`docs/poc-bodyvista-anatomy-audit.md`)**：
   - **抽查主題一：面部年輕化與拉皮／音波（SMAS 筋膜與神經走向）**
     - 比對模型是否具備 SMAS 層、真性/假性韌帶（Zygomatic/Mandibular Retaining Ligaments）、顏面神經分支（顳支、顴支、頰支、下頜緣支）與淺深層脂肪室。
     - 判定其精度為「宏觀醫學教育級」還是達到「臨床整形外科衛教級」。
   - **抽查主題二：自體脂肪／假體隆乳（胸大肌與乳腺腔隙）**
     - 比對模型是否清晰呈現雙平面（Dual Plane）植入腔隙、胸大肌（Pectoralis Major）與乳腺組織分界。
3. **台灣醫療合規與完全離線自託管審核**：
   - 審查術語在地化工作量：檢查所有簡體解剖名詞與台灣醫學會通用繁體標準之差異（如「韌帶」、「肌腱」、「胸大肌腔隙」等）。
   - 審查完全離線能力：檢查專案是否依賴外部 CDN、遠端字體或第三方遙測/雲端 API，確認是否能 100% 離線本地自託管，杜絕病患個資與診所流量外洩。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] 完成 BodyVista 資源結構分析，給出模型資產體積與 WebGL 記憶體開銷量化數據。
- [ ] 產出專科解剖精細度抽查評估報告 `docs/poc-bodyvista-anatomy-audit.md`，包含緻妍診所核心療程對照結論與 GAP 清單。
- [ ] 明確給出離線自託管合規性與台灣繁體名詞校準方案。
