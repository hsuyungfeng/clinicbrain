# 41-01-PLAN: motion-prompt 動態規格字典與緩動預設模組整合至 clinic-visual-batch

## 1. 目標 (Objective)
將 `showheyohtaki/motion-prompt` 開源專案之 144 個精選動效標準名稱、鏡頭運動（camera zoom/pan）、UI 過渡與純 Canvas 2D 緩動曲線（easing curves）規格抽取為輕量模組，收斂整合至 `.agents/skills/clinic-visual-batch/resources/motion_vocab.json`，並更新 `.agents/skills/clinic-visual-batch/SKILL.md`，制定本地大模型（Qwen3.8-27B-FP8 / 3.8 Flash）生成「PageIndex 3 幕衛教卡片」與專科動畫草稿時的動態約束標準。

## 2. 交付成果 (Deliverables)
1. **動態規格字典庫 (`.agents/skills/clinic-visual-batch/resources/motion_vocab.json`)**：
   - 收錄標準動態動詞（`motions`）：`pulse_glow`（光暈脈動）、`focus_zoom`（焦點推進）、`stagger_reveal`（階梯漸入）、`camera_pan`（鏡頭橫搖）、`wipe_reveal`（擦除顯露）、`slice_dissect`（層次切開）、`metabolism_dissolve`（代謝消解）、`vibration_shatter`（震波擊碎）等醫療可視化適用動效。
   - 收錄精確緩動規範（`easings`）：純數值 cubic-bezier 參數（如 `[0.25, 0.1, 0.25, 1.0]`）與純 Canvas/JS 數學公式（`easeOutQuad`, `easeInOutCubic`, `spring_gentle` 等），杜絕模糊的文字描述。
   - 收錄運鏡規格（`camera_actions`）：規範 Scene 1 聚焦、Scene 2 對比切換與 Scene 3 時間軸演進的相機運動參數。
   - 收錄時間預算（`timings`）：嚴格對齊 ClinicBrain 24 秒（3 幕 × 8 秒）架構，定義微互動持續時長（0.3s~1.2s）與循環節奏。
2. **Skill 規範更新 (`.agents/skills/clinic-visual-batch/SKILL.md`)**：
   - 新增第 2.5 節「動態規格與緩動預設規範（Motion & Camera Presets）」。
   - 定義本地 LLM Prompt 提示詞指引：強制模型在輸出 3 幕 Typed IR 時，為每個解剖動作與病理演進指定合規之 `motion_type` 與 `easing`，根除動畫抽搐與僵硬問題。
3. **單元與合規測試套件 (`tests/test_visual_motion_vocab.py`)**：
   - 驗證 `motion_vocab.json` 結構齊全、格式合法。
   - 驗證所有緩動參數符合確定性數學區間（$0 \le t \le 1$）。
   - 驗證所有動效中文術語無簡體字、無違規醫療宣傳詞彙。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] `.agents/skills/clinic-visual-batch/resources/motion_vocab.json` 建立完畢且通過 JSON Schema 驗證。
- [ ] `.agents/skills/clinic-visual-batch/SKILL.md` 包含完整的動效字典引用指南與本地 LLM 約束說明。
- [ ] 執行 `pytest tests/test_visual_motion_vocab.py` 全數通過。
