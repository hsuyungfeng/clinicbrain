      ```
      {"topic_key": "^[a-z0-9-]{3,64}$",
       "title": 字串 ≤30 字,
       "keywords": 1~8 個字串，每個 2~12 字,
       "scenes": 3~5 個物件，每個:
          {"blueprint": "process_diagram"|"contrast"|"timeline",
           "title": ≤16 字,
           "caption": 20~120 字,
           "labels": 0~4 個 {"text": ≤12 字, "tone": "neutral"|"warning"|"optimal"}}}
      ```
      除上列鍵以外的鍵一律拒絕（含 scenes 內）；型別不符拒絕。
    - `validate_visual_text(text)`（所有字串欄位共用，含 title、keywords、labels.text、caption）。實作提醒：`validate_single_faq(item, *, check_dosage, require_doctor_warning)` 只回傳含命中字串的中文 reason，且 `check_dosage` 只對 `answer` 欄生效，因此一律包成 `{"question": "視覺解說文字檢驗", "answer": text}`（保底問句寫死、不含禁詞），`check_dosage=True, require_doctor_warning=False` 呼叫，文字放在 answer 位置：
      1. 禁字元與內容：`< > & " '` 之外的 HTML 風險先以「不得含 `<` `>`」處理；不得含網址（`http`、`www.`、`://`）；不得含「javascript:」。
      2. 價格：`deep_mask_prices(text) != text` 即拒絕。
      3. 簡體字：沿用 `validate_single_faq` 的簡體檢驗（呼叫它，不複製詞表）。
      4. 禁詞：沿用 `validate_single_faq` 的政治立場、保證療效檢驗，並新增 `VISUAL_EXTRA_FORBIDDEN`：永久、終身、一輩子、成為身體一部分、百分之、存活率、保證、一定能、一定會、一定有效、絕對、完全不會、零風險（**不含單獨的「一定」**，避免誤殺「不一定」「一定程度」「一定時間」等自然用語；須有測試：含「一定程度」「不一定」的合格說明不得被拒）；另以正則拒絕任何「數字＋%」與「數字＋％」。
      5. 劑量／處方：沿用 `check_dosage_prescription`。
    - `validate_ir(ir) -> tuple[bool, str]`：回傳 `(ok, code)`，code 為固定英文代碼（`schema_error`、`text_unsafe`、`forbidden_phrase`、`price_leak`、`simplified_chinese`、`dosage_prescription`、`unknown_blueprint`、`ok`），**不回傳任何原文**。reason 反查表（寫死、子字串比對、由上而下）：含「具體金額或價格」→`price_leak`；含「簡體中文」→`simplified_chinese`；含「政治立場」或「違規禁詞」→`forbidden_phrase`；含「用藥劑量或處方」→`dosage_prescription`；其他未知→`text_unsafe`。取得 code 後**丟棄 reason 原文**，不得放入回傳、日誌或例外訊息。
    - 測試用真實形態資料：合格的自體脂肪移植 3 場景 IR 通過；缺鍵、多鍵、場景數 2 或 6、未知 blueprint、caption 過短／過長、含 `<script>`、含網址、含「永久」「存活率」「90%」「保證」、含價格數字、含簡體、含劑量句各自拒絕且 code 正確；code 不含原文。
  </behavior>
