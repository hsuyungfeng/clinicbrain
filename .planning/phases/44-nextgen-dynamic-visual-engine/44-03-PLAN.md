# 44-03-PLAN: 對照場景震顫、修復時間軸金色粒子綻放與 Playwright 確定性全套驗收

## 1. 目標 (Objective)
升級 Scene 2（`drawContrast`）與 Scene 3（`drawTimeline`）之趣味與生動表現，實作傳統側警示紅光不安震顫、微創側流光防護屏障，以及時間軸節點激活時之金色修復微粒子綻放；並執行 Playwright 無頭 Chromium 60fps seek 確定性測試，確保全庫 398 筆動畫升級後 100% 確定、無閃爍、無回歸。

## 2. 交付成果 (Deliverables)
1. **Scene 2 專科對照升級 (`drawContrast`)**：
   - 左側傳統處置（`warning`）：加入基於正弦微頻的「病理顫動（Micro-Tremor）」與紅光警示脈動。
   - 右側微創優勢（`optimal`）：加入順暢平滑的「翡翠綠流光屏障（Flowing Shield）」。
2. **Scene 3 修復時間軸升級 (`drawTimeline`)**：
   - 當前活躍節點激活時，於周圍爆發 8~12 顆金色修復微粒子（Sparkle Dust，隨進度擴散淡出）。
   - 修復歷程文字切換加入平滑透明度淡入淡出（Cross-Fade）。
3. **Playwright 確定性與全系統回歸驗收 (`tests/test_nextgen_visual_engine.py`)**：
   - 驗證在 $u=0$、$u=0.5$、$u=1.0$ 各影格，向前 seek 與向後 seek 的 DOM 狀態與數值 100% 完全相同（確定性保證）。
   - 抽查 5 筆代表性專科主題（HIFU、抽脂、拉皮、自體脂肪、哮吼）於無頭 Chromium 渲染截圖，確認零文字越界、零 NaN 屬性。
   - 由 Tester Hermes 執行獨立驗收與全景矩陣審計簽核。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] Scene 2 與 Scene 3 動效升級完成。
- [ ] `tests/test_nextgen_visual_engine.py` 測試全數通過。
- [ ] Tester Hermes 獨立驗收確認全庫 398 部動畫確定性與視覺表現升級達標。
