# Phase 35 Plan 01: 臺灣基層診所 6 大專科（36 項 ICD-10-CM 常見疾病）概念動畫與衛教知識庫

## 目標 (Objective)
建立臺灣基層診所最常見之 **6 大專科、36 項高頻申報疾病（附 ICD-10-CM 代碼）** 的結構化衛教目錄、3 幕概念動畫（`visual_assets`, `clinic_id IS NULL`）與常見問答（`faq_cache`, `clinic_id IS NULL`, `category='general'`）種子管線。

## 嚴格安全與合規鐵律 (Strict Constraints)
1. **絕對不修改正式資料庫 `clinic.db`**：所有開發與測試僅能在 `tmp_path` 或 `isolated_db_path` 執行；CLI 腳本對正式庫必須預設拒絕（需 `--allow-prod-db` 才放行）。
2. **視覺 IR 合規（100% 通過 `src.visual.ir.validate_ir` 與零阿拉伯數字規則）**：
   - `topic_key` 必須符合 `^[a-z0-9-]{3,64}$`（例如 `icd-j069-uri`、`icd-e119-type-two-dm`，小數點去除或轉 `-`）。
   - **所有可見文字欄位（`title`, `keywords`, `scene.title`, `scene.caption`, `label.text`, `params` 內所有文字標籤与 `step_labels` / `milestones`）絕對禁止出現任何阿拉伯數字 `0-9` 與百分比 `%`！**
     - ⚠️ 特別注意：`E11.9` 必須寫為 **「第二型糖尿病」**（使用中文數字「二」，嚴禁寫「第2型」）；`CKD` 敘述嚴禁寫「1~3期」，須寫為「初期至中期」；體溫警訊於動畫 `caption` 內請寫「持續高燒不退」（不寫阿拉伯數字）。
   - `title` 長度 `1..30` 字；`keywords` 每項 `2..12` 字（共 `1..8` 項）；`scene.title` 長度 `1..16` 字；`scene.caption` 長度 `20..120` 字；`label.text` 長度 `1..12` 字（每幕 `1..4` 個 label）；`params` 內所有文字欄位必須嚴格遵守 `src/visual/blueprints.py` 的 `max_len` 限制（例如 `source.label <= 8`, `container_layers[].label <= 6`, `step_labels[] <= 10`, `contrast.left/right.title <= 8`, `note <= 10`, `core_label <= 6`, `footnote <= 16`, `timeline.milestones[] <= 8`）！
   - **嚴禁非手術內兒科疾病使用 `surgical_action` 模板**！Scene 1 僅可使用 `process_diagram`、`skin_energy`、`neuromuscular`、`dermal_support` 或 `laser_action`。Scene 2 固定使用 `contrast`，Scene 3 固定使用 `timeline`。
3. **FAQ 合規（100% 通過 `src.ingestion.generate_faq.validate_single_faq`）**：
   - 每項疾病的 FAQ `answer` 結尾必須包含具體就醫警訊（如「若出現持續高燒、呼吸困難、劇烈疼痛或意識不清等警訊，請立即就醫或急診評估。」），且不含價格、不含具體藥名與劑量、不含保證療效禁詞、全繁體中文。

## 36 項 ICD-10-CM 疾病清單（6 大專科）

1. **耳鼻喉科／小兒科／家醫科 (`ent_peds_fm`，8 項)**：
   - `J06.9` (`icd-j069-uri`)：急性上呼吸道感染（感冒）
   - `J02.9/J03.90` (`icd-j029-pharyngitis`)：急性咽喉炎與扁桃腺炎
   - `J30.9` (`icd-j309-allergic-rhinitis`)：過敏性鼻炎
   - `J11.1` (`icd-j111-influenza`)：流行性感冒
   - `J20.9` (`icd-j209-bronchitis`)：急性支氣管炎
   - `J01.90` (`icd-j0190-sinusitis`)：急性鼻竇炎
   - `H66.90` (`icd-h6690-otitis-media`)：急性中耳炎（勘誤修正碼 `H66.90`）
   - `J45.909` (`icd-j45909-asthma`)：氣喘與慢性氣道發炎
2. **一般內科／家醫科 (`internal_chronic`，6 項)**：
   - `I10` (`icd-i10-hypertension`)：原發性高血壓
   - `E11.9` (`icd-e119-diabetes`)：第二型糖尿病
   - `E78.00` (`icd-e7800-hyperlipidemia`)：高脂血症與高膽固醇
   - `E79.0/M10.9` (`icd-m109-gout`)：高尿酸血症與痛風
   - `K76.0` (`icd-k760-fatty-liver`)：非酒精性脂肪肝
   - `N18.9` (`icd-n189-ckd`)：慢性腎臟疾病
3. **胃腸肝膽科／內科 (`gi_hepatobiliary`，6 項)**：
   - `A09/K52.9` (`icd-a09-gastroenteritis`)：急性感染性胃腸炎
   - `K21.9` (`icd-k219-gerd`)：胃食道逆流疾病
   - `K29.70` (`icd-k2970-gastritis`)：胃炎與十二指腸炎
   - `K27.9` (`icd-k279-peptic-ulcer`)：消化性潰瘍
   - `K58.9` (`icd-k589-ibs`)：大腸激躁症
   - `K64.9` (`icd-k649-hemorrhoids`)：痔瘡與肛門靜脈曲張
4. **皮膚科 (`dermatology`，7 項)**：
   - `L30.9` (`icd-l309-eczema`)：濕疹與皮膚炎
   - `L50.9` (`icd-l509-urticaria`)：急性與慢性蕁麻疹
   - `L20.9` (`icd-l209-atopic-dermatitis`)：異位性皮膚炎
   - `B35.3/B35.6` (`icd-b353-tinea`)：足癬與股癬黴菌感染
   - `L70.0` (`icd-l700-acne`)：尋常痤瘡與青春痘
   - `B02.9` (`icd-b029-herpes-zoster`)：帶狀疱疹與神經痛
   - `L03.90` (`icd-l0390-cellulitis`)：蜂窩性組織炎
5. **骨科／復健科 (`ortho_rehab`，5 項)**：
   - `M54.50` (`icd-m5450-low-back-pain`)：下背痛與腰部筋膜拉傷
   - `M17.9` (`icd-m179-knee-osteoarthritis`)：膝關節退化性關節炎
   - `S39.011/S93.409` (`icd-s93409-sprain-strain`)：肌腱拉傷與韌帶扭傷
   - `M75.8/M75.00` (`icd-m7500-frozen-shoulder`)：肩部肌腱炎與五十肩
   - `M81.0` (`icd-m810-osteoporosis`)：骨質疏鬆症
6. **泌尿科／婦產科 (`uro_obgyn`，4 項)**：
   - `N30.00/N39.0` (`icd-n3000-uti`)：急性膀胱炎與泌尿道感染
   - `N40.0` (`icd-n400-bph`)：良性前列腺肥大
   - `N76.0` (`icd-n760-vaginitis`)：陰道及外陰發炎
   - `N94.4` (`icd-n944-dysmenorrhea`)：原發性經痛

## 交付檔案與實作規格 (Deliverables)

1. **`data/icd10/primary_care_36_catalog.json`** 與 **`src/visual/icd10_catalog.py`**：
   - `load_icd10_catalog(path=None) -> list[dict]`：載入並驗證 36 筆 ICD-10 疾病資料。
   - `validate_catalog_entry(entry: dict) -> tuple[bool, str]`：驗證單筆條目之 `ir`（透過 `validate_ir` 與零阿拉伯數字檢查）與 `faqs`（透過 `validate_single_faq`）。
   - `seed_icd10_catalog(conn, catalog=None, *, approve_visuals=False, commit=True) -> dict`：
     - 將 36 筆視覺解說卡透過 `src.visual.writer.upsert_assets(conn, assets, source_type="manual", commit=False)` 寫入 `visual_assets`（`clinic_id=None`，`metadata` 含 `{"icd10_code": ..., "specialty": ..., "origin": "icd10_primary_care_catalog"}`）。
     - 若 `approve_visuals=True`，逐筆呼叫 `src.visual.review.set_review_status(conn, topic_key, "approved", commit=False, clinic_id=None)`。
     - 將每筆條目附帶之通用 FAQ 透過 `src.pageindex.faq_writer.upsert_faqs(conn, faqs, source_type="clinic_upload")` 寫入 `faq_cache`（`clinic_id=None`, `category="general"`）。
2. **`scripts/seed_icd10_primary_care.py`**：
   - CLI 參數：`--db`、`--specialty`（選填過濾）、`--dry-run`（唯讀驗證並印出 36 筆摘要，不連 DB）、`--allow-prod-db`（對正式 `clinic.db` 操作時必填，否則於連線前以 exit code 2 拒絕）、`--approve-visuals`。
3. **`tests/test_icd10_primary_care.py`**：
   - 驗證 36 筆 ICD-10 條目數量、6 大專科分佈（8, 6, 6, 7, 5, 4）、`H66.90` 急性中耳炎修正碼存在。
   - 驗證全部 36 筆 `ir` 100% 通過 `validate_ir()`、不含任何阿拉伯數字、且無任何一筆使用 `surgical_action`。
   - 驗證全部 FAQ 100% 通過 `validate_single_faq()`。
   - 驗證 `seed_icd10_catalog` 與 `scripts/seed_icd10_primary_care.py` 在隔離資料庫（`isolated_db_path`）的寫入冪等性與正式庫保護（未帶 `--allow-prod-db` 回傳 exit code 2）。
