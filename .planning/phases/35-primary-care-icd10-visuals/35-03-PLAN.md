# Phase 35 Plan 03: 基層 36 項 ICD-10 疾病之場景 2（誘因對照 `contrast`）與場景 3（臨床病程 `timeline`）圖文語意重構

## 目標 (Objective)
解決目前 36 支基層診所 ICD-10-CM 疾病動畫在 **場景 2 (`contrast`)** 與 **場景 3 (`timeline`)** 的三大圖文語意失真問題：
1. **徹底清除場景 3 (`timeline`) 的「外科隱痕」與「自體脂肪移植物」寫死文字污染**：
   - 目前 `visual_engine.js:823-841` 將第三階段徽章寫死為 `「階段三·穩定隱痕」`，且當 `connectors` 為 `"none"` 或新內兒科模式時，`TIMELINE_STAGE_DESC` 退回 `vessels`（顯示「移植物置入初期，依賴周圍組織液維持初期滋養」）。
   - 為 `timeline.params.connectors` 新增 3 種基層醫療專屬病程模式：
     - **`mucosal_clearance`**（急性感染與黏膜免疫清除歷程 — 適用感冒、咽喉炎、鼻竇炎、中耳炎、流感、支氣管炎、胃腸炎、膀胱炎、陰道炎、蜂窩性組織炎、帶狀疱疹、足癬等感染/急性病）：
       - 繪製黏膜與上皮基底、致病微粒由聚集發炎 -> 免疫抗體與體液沖刷清除 -> 黏膜屏障完整閉合復原。
       - 動態階段說明（`TIMELINE_STAGE_DESC.mucosal_clearance`）：
         1. `"急性發炎反應期，病原刺激黏膜引起充血水腫與不適"`
         2. `"免疫系統活化清除病原，分泌物減少且紅腫逐步消退"`
         3. `"黏膜上皮屏障修復完整，局部防禦功能恢復平穩狀態"`
     - **`homeostasis_control`**（慢性病與代謝生理指標穩定歷程 — 適用高血壓、第二型糖尿病、高血脂、痛風、脂肪肝、慢性腎病、過敏性鼻炎、氣喘、胃食道逆流、慢性胃炎、消化性潰瘍、腸躁症、痔瘡、前列腺肥大、原發性經痛、濕疹、蕁麻疹、異位性皮膚炎、青春痘）：
       - 繪製中央綠色「目標健康安全帶」與一條橫跨畫布的生理指標波形曲線（隨 `u` 由初期大幅高低波動越界 -> 經規律照護逐步收斂振幅 -> 平穩運行於綠色安全帶內，右側浮現器官保護盾）。
       - 動態階段說明（`TIMELINE_STAGE_DESC.homeostasis_control`）：
         1. `"生理指標波動偏離穩定區間，器官組織承受額外負荷"`
         2. `"規律生活作息與醫療調控介入，波動幅度逐步收斂平穩"`
         3. `"長期維持穩定目標區間，降低器官負擔並定期追蹤評估"`
     - **`structural_rehab`**（肌肉骨骼減壓與機能復健歷程 — 適用下背痛、膝退化性關節炎、肌腱拉傷扭傷、五十肩、骨質疏鬆症）：
       - 繪製關節／脊椎力學軸線與兩側肌腱支撐束（隨 `u` 由初期受力歪斜發炎紅暈 -> 急性減壓與溫和伸展消退紅暈 -> 兩側肌力強健對稱支撐、活動順暢）。
       - 動態階段說明（`TIMELINE_STAGE_DESC.structural_rehab`）：
         1. `"急性期組織緊繃或力學負荷失衡，應減少負重保護患部"`
         2. `"發炎反應逐步緩解，配合溫和伸展與物理照護恢復彈性"`
         3. `"強化周邊肌力分散關節負荷，維持良好姿勢預防復發"`
   - 當 `connectors` 為上述三種基層模式（或 `"none"`）時，頂部標題顯示 **`【臨床病程演進與健康管理】`**，三階段徽章顯示 **`「階段一·急性反應」`、`「階段二·調控修復」`、`「階段三·穩定維持」`**（絕不顯示「穩定隱痕」或「移植物置入」；同時補上 `TIMELINE_STAGE_DESC.none` 的中性內科描述以防退回 `vessels`）。
2. **為場景 2 (`contrast`) 新增基層醫療專屬「病理誘因風險 vs 日常防護照護」視覺模式（告別醫美注射套管 `cannula`）**：
   - 在 `src/visual/blueprints.py` 與 `src/web/static/visual_engine.js` 的 `contrast` 新增對稱列舉值：
     - 左側（`left.mode`）新增：
       - **`mucosal_irritant_surge`**（誘因持續刺激／黏膜屏障受損：繪製外來刺激波持續衝擊受損黏膜層，引起紅腫擴散與防線缺口）
       - **`metabolic_mechanical_overload`**（代謝失衡／力學超載累積：繪製管腔／關節承受高壓箭頭擠壓、沉積物堆積與紅暈警示）
     - 右側（`right.mode`）新增：
       - **`barrier_hydration_shield`**（阻隔誘因與保濕修復護盾：繪製翠綠弧形防護盾擋開外來刺激，底層黏膜／角質層平順修復並泛起柔和光暈，**無任何注射套管**）
       - **`lifestyle_homeostasis_load`**（作息飲食調控與力學減壓平衡：繪製平順暢通的雙向平衡流線與對稱支撐結構，**無任何注射套管**）
3. **為 36 筆 ICD-10 疾病逐一量身訂做專屬的場景 2（具體誘因 vs 具體日常照護）與場景 3（專屬病程三階段里程碑與解說）**：
   - 更新 `src/visual/icd10_enrichment.py` 與 `data/icd10/primary_care_36_catalog.json`：
     - **禁止千篇一律使用「延誤處理 vs 及時處理」或「初期不適 -> 症狀高峰 -> 逐漸減輕」**！
     - 每筆疾病的 Scene 2 必須反映該疾病的**真實臨床誘因與照護對比**（例如：過敏性鼻炎「接觸塵蟎冷風 vs 除蟎配戴口罩」；胃食道逆流「宵夜飽食平躺 vs 少量多餐墊高」；痛風「高普林與飲酒 vs 多喝水控飲食」；下背痛「彎腰搬重久坐 vs 核心支撐護腰」；泌尿道感染「憋尿水分不足 vs 足量飲水排空」等）。
     - 每筆疾病的 Scene 3 必須採用對應的 `mucosal_clearance`、`homeostasis_control` 或 `structural_rehab`，並搭配符合該疾病特性的 3 個 `milestones`（`<= 8` 字）與包含「因人而異／醫師評估」專業收尾的 `caption`（`20..120` 字）。

## 嚴格安全與合規鐵律 (Strict Constraints)
1. **`visual_engine.js` 靜態安全與幾何邊界鐵律（必過 `test_visual_engine_static.py` 與 `test_visual_engine_browser.py`）**：
   - **絕對禁止**在 `src/web/static/visual_engine.js`（含程式碼與註解！）出現任何含 `eval` 的單字（連 `evaluate`, `evaluation`, `retrieval` 都不可出現！），以及 `innerHTML`, `outerHTML`, `setTimeout`, `setInterval`, `Math.random`, `Date.now`, `fetch(` 等禁用字。
   - **幾何審計與防跳變鐵律（`test_visual_engine_geometry_audit_and_frame_pop_check`）**：
     - `_variants_for_sweep()` 會自動掃描 `BLUEPRINTS` 內所有頂層 enum（包含 `timeline.connectors` 新增的 3 個值！），在 160 個影格上檢查：
       - 所有元素在 `[5, 795] x [5, 505]` 內（建議嚴格控制在 `[55, 745] x [110, 325]` 主畫布內）。
       - 所有 `<text>` 底部 `vy2 <= 411`（建議 `<text>` 的 `y <= 395`）。
       - 文字與文字不得重疊（`labelOverlap == 0`）。
       - **平滑連續運動（無未宣告的單幀跳變 `> 25` 單位）**：`timeline` 僅在 `u=0.35` 與 `u=0.70` 有宣告的階段切換（`DECLARED_STAGE_CUTS["timeline"] = (0.35, 0.70)`），因此新繪製函式若要切換階段文字或圖形，**切換點必須嚴格設在 `u < 0.35` 與 `u < 0.70`**，或者使用完全連續的曲線（如 `Math.sin` 與線性插值，不移動固定元素的中心超過每幀 25 單位）！
2. **零阿拉伯數字與字數上限鐵律**：
   - 36 筆 `primary_care_36_catalog.json` 的所有 IR 可見文字**絕對禁止出現阿拉伯數字 `0-9` 與 `%`**。
   - 嚴格遵守 `blueprints.py` 的 `max_len`：
     - `contrast.left/right`: `title <= 8`, `note <= 14`, `core_label <= 8` (left only), `footnote <= 16`
     - `timeline`: `milestones` 3 項且每項 `<= 8`
     - `scene.title <= 16`, `scene.caption` `20..120` 字, `label.text <= 12`
3. **絕對禁止修改正式資料庫 `clinic.db`**（所有測試在 `isolated_db_path` 或 `tmp_path` 執行）。
