# Phase 35 Plan 02: 6 大基層專科專屬 SVG 器官動畫藍圖 (`pathology_mechanism`) ＋ 衛教圖表知識萃取與 V2 升級

## 目標 (Objective)
解決 Phase 35-01 中 36 支基層診所 ICD-10-CM 疾病動畫「Scene 1 誤用醫美抽脂離心管 (`process_diagram`)、缺乏專科器官解剖構圖與臨床推理樹支撐」的問題：
1. **Step 1（6 大專科專屬 SVG 器官動畫藍圖 `pathology_mechanism`）**：
   - 在 `src/visual/ir.py`、`src/visual/blueprints.py`、`src/visual/review.py` 與前端引擎 `src/web/static/visual_engine.js` 新增第 14 個藍圖 **`pathology_mechanism`**，支援 `organ_system` 6 大專科器官解剖動態繪製（徹底告別抽脂管）：
     - `respiratory_mucosa`（耳鼻喉/小兒呼吸道，8 病）：繪製呼吸道／鼻竇／中耳腔纖毛黏膜切面、病原飛沫或過敏原附著、黏膜充血腫脹與纖毛排痰修復動態。
     - `vascular_metabolic`（三高與代謝內科，6 病）：繪製動脈血管腔內壁／胰島受體／肝腎代謝濾網、血壓阻力／血脂斑塊／尿酸結晶沉積與代謝平衡動態。
     - `gi_tract`（胃腸肝膽科，6 病）：繪製食道下括約肌與胃十二指腸黏膜／腸道管腔、胃酸逆流或黏膜發炎破損、以及黏膜保護屏障修復動態。
     - `skin_barrier`（皮膚科，7 病）：繪製表皮角質磚牆屏障／真皮毛囊皮脂腺／皮下神經節、過敏原或黴菌穿透／毛囊發炎／神經水泡與屏障修復動態。
     - `joint_spine`（骨科復健科，5 病）：繪製椎間盤筋膜／膝關節軟骨滑液囊／肩旋轉肌袖／骨小樑、力學磨損發炎與肌力支撐減壓動態。
     - `uro_pelvic`（泌尿婦產科，4 病）：繪製膀胱尿道黏膜／前列腺包覆尿道／骨盆腔平滑肌、逆行性細菌感染或壓迫痙攣與沖刷舒緩動態。
2. **Step 2（台灣權威衛教爬蟲補充 ＋ Local LLM 疾病知識與圖表結構萃取）**：
   - 建立 `src/visual/icd10_enrichment.py` 與 `scripts/enrich_icd10_primary_care.py`：
     - 支援台灣公開衛教圖表結構與臨床重點萃取（含離線權威衛教知識庫種子與可選 HTTP 衛教單張爬蟲補充，遵守沙盒與純本地推理原則），並可呼叫地端 `Qwen3.8-27B`（`local_llm_call`）或結構化臨床蒸餾器，產出每項疾病的 **四段式臨床推理摘要（致病機轉 `pathophysiology`、臨床表現 `clinical_presentation`、處置與居家照護 `management_care`、紅旗警訊与長期追蹤 `red_flags_prevention`）** 與 **專科解剖圖表映射（`organ_system`, `organ_label`, `lesion_label`, `trigger_label`, `defense_label`, `step_labels`）**。
     - 全面升級 `data/icd10/primary_care_36_catalog.json`：將 36 筆 ICD-10 疾病的 Scene 1 全面升級為 `pathology_mechanism`（各自對應其專科 `organ_system` 與專屬器官解剖標籤），並豐富 Scene 1/2/3 的臨床圖解文案與 `clinical_summary` 四段式結構。

## `pathology_mechanism` 藍圖規格定義 (Blueprint Specification)

於 `src/visual/blueprints.py` 與 `src/web/static/visual_engine.js` 同步定義：

```python
    "pathology_mechanism": {
        "params": {
            "organ_system": {
                "type": "enum",
                "values": (
                    "respiratory_mucosa",
                    "vascular_metabolic",
                    "gi_tract",
                    "skin_barrier",
                    "joint_spine",
                    "uro_pelvic",
                ),
            },
            "organ_label": {"type": "text", "max_len": 8},
            "lesion_label": {"type": "text", "max_len": 8},
            "trigger_label": {"type": "text", "max_len": 8},
            "defense_label": {"type": "text", "max_len": 8},
            "severity_level": {"type": "int", "min": 1, "max": 5},
            "accent_fill": {"type": "palette"},
            "step_labels": {
                "type": "list",
                "min": 3,
                "max": 3,
                "item": {"type": "text", "max_len": 10},
            },
        },
        "defaults": {
            "organ_system": "respiratory_mucosa",
            "organ_label": "呼吸道黏膜",
            "lesion_label": "充血發炎區",
            "trigger_label": "外來致病源",
            "defense_label": "黏膜屏障修復",
            "severity_level": 3,
            "accent_fill": "warn",
            "step_labels": ["致病因子刺激", "局部組織發炎", "屏障逐步修復"],
        },
    },
```

### `drawPathologyMechanism(ctx, params, u)` 6 大專科器官幾何設計規範：
1. **共用框架（y: 24..365）**：
   - 背景：`ctx.rect({ x: 0, y: 0, width: 800, height: 510, fill: "#0f172a", "data-bg": "1" })` 與外框 `{ x: 24, y: 24, width: 752, height: 462, rx: 16, fill: "#1e293b", stroke: "#334155", "stroke-width": 2 }`。
   - 頂部解剖標頭列（`y: 42..64`）：顯示專科構造膠囊標籤 `organ_label`、`trigger_label`、`lesion_label`、`defense_label`。
   - 隨時間進度 `u`（`0..1`）分為三幕動態：
     - `u < 0.35`（致病因子入侵／力學或代謝負荷階段）
     - `0.35 <= u < 0.70`（局部組織發炎／黏膜受損／管腔狹窄或神經壓迫高峰階段）
     - `u >= 0.70`（醫療照護介入、屏障修復、管腔暢通與穩定階段）
   - 底部呼叫 `drawStepPills(ctx, params.step_labels, u)`。
2. **6 大 `organ_system` 專屬器官幾何（左側主解剖圖 `x: 55..510, y: 85..345` ＋ 右側微觀機轉面板 `x: 535..745, y: 85..345`）**：
   - `respiratory_mucosa`：繪製彎曲氣道與鼻咽耳咽管腔、排列整齊的纖毛上皮細胞柱、動態飄入的致病微粒、充血腫脹的黏膜層（隨 `u` 先腫脹發紅、後消腫恢復纖毛擺動與通氣箭頭）。
   - `vascular_metabolic`：繪製橫向動脈血管壁剖面與內皮細胞、管腔內流動的紅血球與代謝粒子（血脂/血糖/尿酸結晶）、隨 `u` 展示管壁壓力或沉積物由聚集轉為平穩代謝流通。
   - `gi_tract`：繪製食道與胃囊／腸道彎曲管腔剖面、下食道括約肌閥門、胃酸液面波紋與黏膜保護層（隨 `u` 展示胃酸逆流或黏膜紅腫潰瘍點，後由翠綠保護膜覆蓋修復）。
   - `skin_barrier`：繪製表皮角質磚牆層、真皮層毛囊與皮下微血管／神經纖維（隨 `u` 展示過敏原或微生物穿透角質縫隙引起紅斑風疹或毛囊腫脹，後角質磚牆緊密閉合修復）。
   - `joint_spine`：繪製上下骨骼端（椎體或股骨/脛骨端）、中間關節軟骨墊與滑液囊、兩側肌腱韌帶束（隨 `u` 展示負荷壓迫與發炎紅暈，後關節間隙恢復、肌腱支撐穩定）。
   - `uro_pelvic`：繪製膀胱腔體與下行尿道管腔（兩側包覆前列腺或骨盆平滑肌環）、液體流向箭頭（隨 `u` 展示細菌逆行附著或平滑肌緊繃壓迫，後經水流沖刷與平滑肌舒張恢復順暢）。
