# 43-01-PLAN: 影片佇列引擎實作、直接讀取資料庫 IR 渲染與雙尺寸支援

## 1. 目標 (Objective)
建立核心影片佇列渲染模組 `src/visual/video_queue.py`，支援直接從 `clinic.db` 之 `visual_assets` 表讀取已核准的 `ir_json`，動態生成記憶體 bundle 並透過 Playwright Chromium + ffmpeg 進行高精準度無頭逐格截圖與 H.264 影片合成；支援 16:9 橫屏（1920×1080）與 9:16 豎屏（1080×1920）雙重解析度規格，並實作 SHA-256 增量快取跳過機制。

## 2. 交付成果 (Deliverables)
1. **影片佇列渲染模組 (`src/visual/video_queue.py`)**：
   - `render_asset_to_video(db_conn, topic_key, output_path, aspect="landscape", fps=24, hold_sec=2.5, force=False)`：
     - 自動自 `visual_assets` 查詢 `ir_json`、`title` 與診所資訊。
     - 計算 IR 內容 SHA-256，若目標 MP4 存在且 SHA-256 吻合則冪等跳過。
     - 支援 `landscape` (1920×1080, 適用電視看板) 與 `portrait` (1080×1920, 適用 Reels/LINE)。
     - 自動配置臨時 HTTP 伺服器並載入通用播放器 `player.html`。
     - 逐格 seek 截圖並調用 `/usr/bin/ffmpeg` 合成為 `yuv420p` H.264 MP4。
   - `batch_render_queue(db_conn, limit=None, aspect="landscape", skip_existing=True)`：
     - 查詢所有 `review_status='approved'` 之視覺資產，批次依序處理。
     - 回傳渲染統計摘要（成功、跳過、失敗筆數與耗時）。
2. **單元與渲染驗證測試 (`tests/test_visual_video_queue.py`)**：
   - 驗證 SHA-256 增量快取計算邏輯。
   - 驗證橫屏與豎屏尺寸參數正確傳遞至 Playwright Viewport。
   - 針對單一測試主題執行完整端到端 1 秒快速錄製測試（低 fps/縮短時長以加速測試）。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] `src/visual/video_queue.py` 實作完成，可直接讀取資料庫並輸出 MP4。
- [ ] 支援 16:9 橫屏與 9:16 豎屏兩種尺寸切換。
- [ ] 執行 `uv run pytest tests/test_visual_video_queue.py` 全數通過。
