# 43-02-PLAN: 夜間批次離峰排程整合、增量快取跳過與 CLI 工具

## 1. 目標 (Objective)
建構命令列批次工具 `scripts/run_video_render_queue.py`，並將影片自動渲染佇列無縫整合進夜間離峰批次排程 `src/batch/runner.py`（階段 8），實作平滑限流、中斷續跑與檔案儲存路徑標準化（`data/videos/`）。

## 2. 交付成果 (Deliverables)
1. **影片渲染 CLI 入口 (`scripts/run_video_render_queue.py`)**：
   - 支援參數：`--topic-key`（單筆特定主題）、`--all`（全庫 approved 資產）、`--limit N`（批次上限）、`--aspect` (`landscape`|`portrait`|`both`)、`--force`（強制覆寫既有影片）、`--dry-run`（僅盤點待渲染主題而不實質啟動 Chromium）。
   - 終端進度輸出與摘要報表（包含渲染解析度、位元率、檔案大小與總耗時）。
2. **夜間批次第 8 階段整合 (`src/batch/runner.py`)**：
   - 於夜間批次新增階段 8（可透過旗標 `--skip-video-render` 或配置停用）。
   - 於深夜離峰時間自動掃描當日新 approved 且尚未生成 MP4 的視覺資產，依序排程渲染，完全不干擾日間看診系統負載。
3. **整合測試套件 (`tests/test_video_queue_cli_and_batch.py`)**：
   - 驗證 CLI 各參數解析與 `--dry-run` 行為。
   - 驗證批次 runner 呼叫時正確處理已存在檔案之跳過邏輯。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] `scripts/run_video_render_queue.py` 支援 `--dry-run` 與特定主題渲染。
- [ ] 夜間批次 `src/batch/runner.py` 整合影片渲染階段並支援斷點續跑。
- [ ] 執行 `uv run pytest tests/test_video_queue_cli_and_batch.py` 全數通過。
