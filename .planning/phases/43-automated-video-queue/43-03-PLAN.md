# 43-03-PLAN: 管理端 API、Web 後台全景矩陣影片狀態與下載預覽

## 1. 目標 (Objective)
在 FastAPI 服務層新增影片狀態查詢與單筆非同步渲染觸發 API，並在管理後台（`index.html` & `app.js`）的「🎬 醫學動畫管理」清單與「全景審核矩陣」中，實裝影片渲染狀態標籤（`[📹 MP4 已就緒]` / `[⏳ 待渲染]`）、支援在線預覽播放與一鍵下載 MP4，完成實機業務閉環。

## 2. 交付成果 (Deliverables)
1. **FastAPI 管理端 API 端點 (`src/api/routes/admin.py` 或 `src/api/routes/visual.py`)**：
   - `GET /api/v1/admin/visual/videos/{topic_key}`：查詢該主題 MP4 是否已存在、檔案大小、橫豎屏可用性與下載網址。
   - `POST /api/v1/admin/visual/videos/{topic_key}/render`：醫師在後台點選「🎬 立即渲染影片」，由 FastAPI `BackgroundTasks` 非同步啟動渲染。
   - `GET /api/v1/admin/visual/videos/{topic_key}/download`：下載已生成的 H.264 MP4 影片（支援 `aspect=landscape` 或 `aspect=portrait`）。
2. **Web 後台 UI 擴充 (`src/web/static/app.js` & `src/web/static/index.html`)**：
   - 在動畫卡片中新增「📹 下載 MP4 (16:9 / 9:16)」操作按鈕。
   - 支援原生 HTML5 `<video controls>` 燈箱（Lightbox）在線即時播放 MP4。
   - 全景矩陣新增影片覆蓋率指標（如：`已渲染 MP4: 120 / 398`）。
3. **端到端 API 與 UI 契約測試 (`tests/test_visual_video_api.py`)**：
   - 驗證 API 端點權限（需 `X-API-Key` 驗證）、安全路徑檢查（防止目錄穿越攻擊）與下載串流回應。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] 管理 API 支援查詢、非同步觸發與下載 MP4 檔案。
- [ ] Web 後台支援按鈕觸發與在線播放。
- [ ] 執行 `uv run pytest tests/test_visual_video_api.py` 全數通過。
