# Phase 43: 自動化動態解說動畫影片佇列 (Automated Explainer Video Queue)

## 1. 階段目標與業務價值
本階段旨在將 ClinicBrain 資料庫內已核准之 **398 筆 24 秒醫學向量動畫資產** 實體化，自動批量渲染為高品質、無聲、符合醫療衛教規範之 **H.264 MP4 影片**，解決診間看板、衛教平板與社群媒體短影音的需求痛點。

核心任務包含：
1. **離線自動渲染佇列引擎 (`src/visual/video_queue.py`)**：
   - 突破原型腳本 `demo/visual/render_video.py` 需依賴磁碟靜態 bundle 檔案之限制，支援直接以資料庫 `visual_assets` 的 `topic_key` 或批次查詢動態渲染。
   - **多媒體雙尺寸支援**：
     - **16:9 橫屏 (1920×1080 / 1280×720)**：供診間、候診區電視看板無縫循環輪播。
     - **9:16 豎屏 (1080×1920)**：供衛教平板直立解說、Instagram Reels 與 LINE 官方帳號推播。
   - **SHA-256 增量快取防重染**：比對 `ir_json` 之 SHA-256 雜湊與磁碟既有影片，IR 內容未變且影片完整時自動跳過，避免浪費 GPU/CPU 算力。
2. **夜間批次排程與 CLI 工具整合**：
   - 整合至夜間批次排程 `src/batch/runner.py`（階段 8：動態影片批次渲染佇列），在離峰深夜無人看診時段自動補齊新核准主題之 MP4。
   - 提供專屬 CLI `scripts/run_video_render_queue.py`，支援 `--topic-key`、`--batch`、`--aspect`、`--force` 與進度條顯示。
3. **管理端 API 與 Web App 預覽下載**：
   - 後台全景審核矩陣整合「🎬 影片狀態」徽章（已渲染/待渲染）。
   - 提供管理 API 端點（`POST /api/v1/admin/visual/render-video`），支援醫師在線預覽播放與一鍵下載 MP4。

## 2. 核心約束與醫療法規標準
- **確定性渲染**：嚴格每秒 24 幀（24fps），24 秒動畫恰好 576 幀 + 2.5 秒結尾預約卡（60 幀），總計 636 幀。
- **純本地離線保證**：利用本地 Playwright Chromium 與系統 `/usr/bin/ffmpeg` 本機合成，全程無任何外部雲端轉碼依賴。
- **合規水印與免責**：影片結尾預約卡畫面強制包含「本解說僅供衛教參考，實際療程與處置需由專科醫師親自評估」繁體中文法定免責字樣。
