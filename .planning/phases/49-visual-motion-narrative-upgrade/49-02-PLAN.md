# 49-02-PLAN: 抽樣渲染 MP4 與 `hermes-test` 目視／成片驗收

## 1. 目標 (Objective)
驗證 `visual_engine.js` 升級（含 49-01 智能平衡分段字幕）在 Phase 43 離線影片管線 (`src/visual/video_queue.py`) 中的實際成片品質，透過 `herdr` 委派 `hermes-test` (`wA:p3`) 完成 3 個跨專科代表療程的 16:9 / 9:16 MP4 強制重渲染、幀截圖抽檢與驗收報告。

## 2. 執行步驟 (Tasks)
1. **強制重渲染 3 代表療程 MP4（16:9 與 9:16）**：
   - 目標主題：
     1. `icd-k279-peptic-ulcer`（消化性潰瘍）
     2. `tree-3503264627-structural-autologous-rhinoplasty`（結構式自體軟骨全方位隆鼻手術）
     3. `tree-ultraformer-mpt-hifu`（Ultraformer MPT 媚必提微脈衝音波拉提）
   - 執行指令：
     ```bash
     .venv/bin/python scripts/run_video_render_queue.py --topic-key icd-k279-peptic-ulcer --aspect both --force
     .venv/bin/python scripts/run_video_render_queue.py --topic-key tree-3503264627-structural-autologous-rhinoplasty --aspect both --force
     .venv/bin/python scripts/run_video_render_queue.py --topic-key tree-ultraformer-mpt-hifu --aspect both --force
     ```
2. **透過 `herdr` 委派 `hermes-test` (`wA:p3`) 執行成片與多幀抽檢**：
   - 使用 `herdr pane send-text wA:p3 ...` 請 `hermes-test` 驗證：
     - 6 支 MP4（3 主題 × landscape/portrait）檔案存在、時長約 24.0s、`ffprobe` 編碼正常。
     - 抽幀檢查 Scene 1 (`t=0.6s, 4.0s`)、Scene 2 (`t=12.0s`)、Scene 3 (`t=20.0s`) 的分段字幕標記已不再是 `1/1`（均已自動平衡切分為 `1/2`、`2/2` 或 `1/3`…）、無截斷、16:9 與 9:16 構圖安全無裁切。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] 3 個代表療程共 6 支 MP4（16:9 & 9:16）透過 `--force` 成功產出且 `ffprobe` 驗證通過。
- [ ] `hermes-test` 回報三療程字幕皆已正確多段同步顯示（非 `1/1`），無文字截斷、無畫面溢出或渲染異常。
