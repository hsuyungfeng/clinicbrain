# Phase 23 PRD：網站擷取器（PageIndex 素材自動化）

## 使用者需求（原文摘要）
想要增加爬蟲，擷取如 https://www.nu-vendome.com/location-detail/Taichung/ 這類網站的資訊，作為 PageIndex 素材，減少人力。

## 需求
- R1：輸入網址，擷取頁面中的結構化欄位（機構名稱、地址、電話、營業時間、服務項目、醫師姓名與專長）。
- R2：擷取結果轉為草稿（FAQ 草稿與／或 PageIndex 樹草稿），寫入 `pending`，經醫師審核後才對外可見。
- R3：遵守 robots.txt、請求間隔節流、明確 User-Agent；單頁失敗不中斷批次。
- R4：不保存外部頁面的非必要個資；每筆草稿保存來源 URL 與擷取時間於 metadata。
- R5：價格、療效保證、藥品劑量等內容必須經既有合規檢驗與價格屏蔽。
- R6：提供 CLI 入口；Web 入口由 Phase 24 串接。

## 風險與限制（需在規劃時確認）
- 目標為第三方網站，須確認其使用條款與擷取合法性；規劃前應由使用者確認擷取對象清單。
- 網站改版會使解析器失效，需有欄位缺失偵測與告警。
- 外部內容不可直接當作診所權威來源（不得標記為 `clinic_upload`）。
