BATCH-03 的執行本體：把 09-03/09-04 的元件組成可預演、可追蹤、LLM 不可用時優雅跳過、有成本上限的夜間批次，並提供 CLI。

Output: run_log.py、runner.py、scripts/run_nightly_batch.py 與兩個測試檔。

設計決定：
- dry-run 不呼叫 LLM（含健康檢查）：只要資料庫唯讀 + 清單檔 + 統計即可規劃，可在 LLM 關閉時執行，結果是確定性的。報告會註明「LLM 狀態：dry-run 未檢查」。
- LLM 健康檢查失敗視為正常情境（機器休眠、llama-server 未啟）：結束碼 0，讓 systemd 不誤判失敗；日誌留下 warning 供查閱。
- 持續失敗的主題（LLM 每次輸出都被驗證剔除）會在之後每晚重試並佔用名額，屬已知限制（受 max_faq_topics 上限約束），由日誌中的 rejected 計數讓人類發現後調整清單。
- local_llm_call 逾時會被 llm_client 轉成 LocalLLMUnavailableError，因此單次逾時會讓整個批次提前優雅結束（結束碼 0，下一晚重試）；此為已知限制，記入 AGENTS.md（09-06），不另做逾時重試。
</objective>
