# 39-03-PLAN: 雙引擎架構（DeepSeek 提煉解剖事實 + Local 35B 編譯動畫）與解剖標記擴充

## 1. 目標 (Objective)
升級視覺動畫批次生成管線為 **Teacher-Student 雙引擎架構**：
1. **Step 1 (DeepSeek 雲端醫學大腦 - 極低 Token / 高深度知識)**：
   調用 DeepSeek 檢索並提煉各基層疾病的「精確解剖部位與三幕臨床事實卡 (Anatomy Fact Sheet)」，消除醫學幻覺，精確鎖定解剖結構（如口咽扁桃腺隱窩、牙釉質牙本質髓腔、頸深筋膜與項韌帶等）。
2. **Step 2 (本地 8080 Ornith-35B 本地動畫編譯器 - 免費 / 高速 / 無限自癒)**：
   由本機 `llama-server` 接收事實卡，在本地將其編譯為嚴格合規的 24 秒（3 幕 × 8 秒）Typed IR JSON，負責繁體中文潤飾、零阿拉伯數字清洗、免責聲明裝配與格式自癒。
3. **擴充解剖庫映射 (Anatomy Target & Visual Markers)**：
   第一幕 `pathology_mechanism` 帶入具體的 `anatomy_target`、`organ_label`、`lesion_label`，並於前端 `visual_engine.js` 呈現解剖結構與病灶位置。
4. **重做示範 3 疾病 (Redo 3 Diseases)**：
   重新生成並更新資料庫中既有的 3 筆示範資產（急性扁桃腺炎、深層蛀牙、落枕），驗收解剖標記與雙引擎流暢度。

---

## 2. 交付任務與執行步驟 (Execution Steps)

### Task 1: 藍圖規格與前端繪製擴充解剖定位 (Anatomy Target & Visual Markers)
- 在 `src/visual/blueprints.py` 的 `pathology_mechanism` 規格中，確認 `organ_label`、`lesion_label`、`trigger_label`、`defense_label` 欄位約束（長度 2~8 字）。
- 在 `src/web/static/visual_engine.js` 的 `pmDrawFrame` 與 `drawPathologyMechanism` 中，將 `organ_label` 與 `lesion_label` 立體標示於畫布上方/核心解剖部位，標註病灶焦點。

### Task 2: 雙引擎批次管線升級 (`scripts/generate_nhi200_visual_batch.py`)
- **Step 1 提煉函式 `extract_anatomy_fact_sheet(item, archetype)`**：
  - 調用 DeepSeek API 產出純文字/精簡 JSON 之醫學事實卡（包含：具體解剖結構、病原/病理機制、照護對比要點、復原歷程）。
  - 單次耗費約 100~150 tokens，反應時間 1~2 秒，成本極低。
- **Step 2 本地編譯函式 `compile_visual_ir_local(item, archetype, fact_sheet)`**：
  - 調用本地 8080 `local_llm_call()`（Ornith-1.5-35B-Q5_K_M）。
  - 將事實卡編譯為 3 幕 24 秒 Typed IR，帶入精確的 `anatomy_target`、`organ_label` 與 `lesion_label`。
  - 本地自動通過 `post_process_self_heal` 進行阿拉伯數字過濾與免責聲明補充。
- **雙模回退保護**：
  - 若 DeepSeek API 不可用，Step 1 自動回退至本地預設解剖知識庫；
  - 若本地 8080 負載過重，Step 2 可平滑切換至 DeepSeek 一站式補位。

### Task 3: 重做 3 筆示範疾病 (Redo 3 Diseases)
- 針對 `nhi-w003-j0390`（急性扁桃腺炎）、`nhi-d001-k029`（深層蛀牙）、`nhi-c002-m542`（落枕）透過新雙引擎管線重新生成。
- 透過 `upsert_assets()` 更新資料庫內容，維持 `review_status='pending'`，遞增 `content_version`。

### Task 4: 測試套件更新與 Hermes 窗格驗收
- 更新 `tests/test_nhi_batch_generator.py`，加入雙引擎流水線測試與解剖標記檢驗。
- 透過 `herdr pane run wA:p3` 執行全套測試，確保 100% 通過。
