# 39-01-PLAN: 健保 200 疾病目錄建檔、88 既有資產篩除器與 DeepSeek API 客戶端

## 1. 目標 (Objective)
建立衛福部健保署基層診所 200 大常見疾病標準化 JSON 目錄（西醫 ~120、中醫 ~50、牙醫 ~30），實作能自動比對目前資料庫既有 88 個主題的語意去重篩選器（Filter / Deduplicator），並建立串接 DeepSeek API (`deepseek-chat`) 的安全客戶端模組（支援超時重試與本機 8080 `llama-server` 雙模降級）。

## 2. 交付成果 (Deliverables)
1. `data/nhi_primary_care_200.json`：
   - 收錄使用者提供之健保署 200 大門診疾病分類（科別、ICD-10-CM 建議代碼、中文名稱、常見症狀、處置重點）。
2. `src/visual/nhi_dedup.py`：
   - 提取資料庫中現有已核准之 88 個主題（36 項基層 ICD-10、49 棵醫美外科樹、3 棵浩康診所樹）。
   - 進行別名、ICD-10 與關鍵字比對，自動輸出「已存在清單」與「剩餘待生成清單（約 112 項）」。
3. `src/pageindex/deepseek_client.py`：
   - 封裝官方 DeepSeek API 介面（支援環境變數 `DEEPSEEK_API_KEY`，預設端點 `https://api.deepseek.com`）。
   - 支援結構化輸出引導、超時防護與 `LocalLLMUnavailableError` 等價之例外處理。
   - 具備自動降級開關：若 DeepSeek API 憑證失效或連線中斷，可平滑退回本機 8080 `local_llm_call`。
4. `tests/test_nhi_dedup_and_deepseek.py`：
   - 驗證 200 項目錄之結構完整度。
   - 驗證去重邏輯精準篩除既有 88 個主題，無誤殺、無漏篩。
   - 模擬 DeepSeek API 回應與本機降級機制。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] 200 疾病目錄建檔完成，涵蓋西醫、中醫、牙醫三大類。
- [ ] 執行 `python3 src/visual/nhi_dedup.py` 能精確識別既有 88 個主題，並標示出需新生成的 ~112 項清單。
- [ ] DeepSeek 客戶端通過模擬呼叫測試與 Fallback 驗證。
- [ ] 專屬單元測試全數通過（`pytest tests/test_nhi_dedup_and_deepseek.py`）。
