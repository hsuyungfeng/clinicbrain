# 39-04-PLAN: Herdr 多 Agent 協作驗收（Hermes 測試監控 → Agy 查核與自動修復）與全套回歸

## 1. 目標 (Objective)
實施多 Agent 協同閉環：利用 `herdr` 調度 **Hermes Agent** 執行批次監控、`validate_ir` 門檻檢查與無頭瀏覽器渲染回歸測試；由 **Agy Agent** 捕捉失敗項、進行代碼自癒修復；最後進行全系統廣域回歸測試與文件規範更新。

## 2. 交付成果 (Deliverables)
1. **Herdr 協同調度規範與腳本 (`scripts/herdr_phase39_monitor.py`)**：
   - 封裝 `herdr` CLI 指令，定義 Hermes 與 Agy 在不同 Pane 間之通訊與狀態回報機制。
   - Hermes 職責：
     1. 執行 `pytest tests/test_nhi_*` 專屬測試。
     2. 啟動 Playwright 執行 `tests/test_visual_engine_browser.py`，驗收 24 秒動畫在 Chrome 核心下的 60fps 渲染確定性。
     3. 產生測試報告 JSON 並輸出至 `.planning/phases/39-nhi200-deepseek-visual-scale/39-HERMES-AUDIT.md`。
   - Agy 職責：
     1. 讀取 Hermes 測試報告中的失敗邊界。
     2. 針對圖形溢出、時間軸未對齊或格式問題進行最小化代碼修復。
     3. 維護受保護文件零非預期改動（`AGENTS.md` 僅增不減）。
2. **端到端全系統回歸驗證**：
   - 執行全套系統回歸測試，確認現有功能無破壞性回歸。
3. **規範與交接文件**：
   - 更新 `AGENTS.md`（新增 2.29 章節：台灣健保 200 大核心疾病動畫目錄與 24 秒規範）。
   - 產出 `39-SUMMARY.md` 記錄執行歷程、去重成果與醫生審核指引。

## 3. 驗收標準 (Acceptance Criteria)
- [ ] Hermes Agent 執行無頭渲染與 IR 驗收測試，形成結構化審計報告。
- [ ] Agy Agent 完成所有缺陷查核與修復，專屬測試 100% 通過。
- [ ] 全套回歸測試通過無新增失敗。
- [ ] 資料庫 `clinic.db` 既有 88 筆資產完整保留，新草稿以 `pending` 妥善寫入，等待醫師簽核。
