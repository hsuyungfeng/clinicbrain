# Phase 39: 台灣健保 200 大核心疾病視覺動畫規模化（DeepSeek 提煉、24 秒三幕動畫、去重篩選與 Herdr 閉環）

## 1. 階段定位與目標
依據使用者指示，導入中華民國衛福部健保署最新門診醫療統計之「台灣基層診所最常見疾病與症狀」（西醫約 120 項、中醫約 50 項、牙醫約 30 項，共約 200 項核心診斷清單）。
將清單與資料庫現有已核准之 **88 個主題動畫**（含 36 項基層 ICD-10、49 棵醫美外科推理樹、3 棵浩康診所樹）進行自動化語意比對與精確去重篩除，產出剩餘約 112 筆待建置的新疾病目錄。
介接雲端 **DeepSeek API**（`deepseek-chat` / `deepseek-reasoner`，支援本地 8080 `llama-server` 雙模降級），批次生成每部 **精確 24 秒（3 幕 × 8 秒）** 之高解析度向量動畫草稿，並透過 `herdr` 調度 Hermes 測試與 Agy 修復，達成自動化閉環。

## 2. 核心規範與硬性約束
- **去重篩除**：自動從 200 項健保清單中排除資料庫現有的 88 個主題（`autologous-fat-grafting`, 36 筆 `icd-*`, 49 筆醫美外科樹等），絕不重複生成。
- **24 秒動畫規範**：
  - Scene 1（病理/解剖機轉）：8 秒 (`duration_sec: 8.0`)
  - Scene 2（對照組：風險 vs 處置/優勢）：8 秒 (`duration_sec: 8.0`)
  - Scene 3（生理修復/病程時間軸）：8 秒 (`duration_sec: 8.0`)
  - 總時長精確為 24 秒。
- **DeepSeek API 介接與安全**：
  - Base URL：`https://api.deepseek.com`
  - 模型：`deepseek-chat`
  - 需妥善管理金鑰環境變數 `DEEPSEEK_API_KEY`；提供本地 `llama-server`（8080）雙模降級機制。
- **專科藍圖圖元擴充**：
  - 牙醫專科：齲齒窩洞、牙髓發炎、牙周萎縮與洗牙、根管抽神經。
  - 中醫傷科與內科：經絡針灸氣血、穴位電針、拔罐除濕、肌肉沾黏小針刀。
  - 內科代謝：胰島素受體門閥、SGLT2 尿糖排泄、微血管病變。
- **Fail-Closed 醫療法規**：
  - 零阿拉伯數字、零價格洩漏、無保證療效、場景 3 結尾固定就醫評估警語。
  - 所有生成動畫一律為 `review_status = 'pending'`，需醫師簽核，簽核後自動昇華一般醫學。
- **Herdr 角色協同**：
  - Hermes Agent 執行自動化測試（`validate_ir`、Playwright 瀏覽器渲染測試）。
  - Agy Agent 查核失敗項目、執行自癒重試並修復代碼。
