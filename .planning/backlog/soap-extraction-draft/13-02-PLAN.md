## RED 階段（先寫會失敗的測試）

建立 `tests/test_soap_extractor.py`，定義測試案例：
1. **醫美/自費處置萃取測試（以截圖真實案例為本）**：
   - 輸入：
     - S: "Patient reports forehead wrinkles and a painful scar near corner of eye."
     - P: "1. Botulinum toxin injection for forehead wrinkles. 2. Observation of laser-treated areas for healing. 3. Follow-up 4 to 6 months."
     - 對話摘要：「醫師與病人討論雷射術後恢復情況，病人表示眼角疤痕較痛，醫師說明皮膚較敏感...解釋肉毒桿菌效果在施打後一段時間才會顯現...」
     - 診斷碼: `L90.5` (疤痕及皮膚纖維化), `L90.8` (皺紋)
     - 醫令: `Z0008` (自費 pico laser 蜂巢皮秒)
   - 預期輸出包含 2 筆 FAQ：
     - FAQ 1: 問題關於皮秒雷射術後眼角疤痕敏感疼痛，解答說明皮膚敏感與照護警訊，`category == 'special'`, `topic_key == 'facial-scarring'`。
     - FAQ 2: 問題關於肉毒桿菌除皺效果多久出現，解答說明需一段時間發揮及維持期，`category == 'special'`, `topic_key == 'botox-forehead-lines'`。
2. **一般疾病萃取與分流測試**：
   - 輸入：感冒急性上呼吸道感染（ICD-10: J00）之主訴與居家照護說明。
   - 預期輸出：`category == 'general'`, `clinic_id is None`。
3. **缺少核心臨床資訊之拒絕測試**：
   - 輸入缺少 P（計畫與衛教）或診斷為空時，回傳空清單或明確錯誤，不捏造問答。

## GREEN 階段（實作萃取引擎）

建立 `src/ingestion/soap_extractor.py`：
1. 定義資料結構：
   ```python
   @dataclass
   class SoapInput:
       subjective: str
       objective: str
       assessment: str
       plan: str
       dialogue_summary: str
       icd10_codes: list[str] = field(default_factory=list)
       order_codes: list[str] = field(default_factory=list)
       clinic_id: Optional[str] = None

   @dataclass
   class ExtractedFaqItem:
       question: str
       answer: str
       category: str          # 'special' or 'general'
       clinic_id: Optional[str]
       topic_key: str
       source_icd10: Optional[str] = None
       source_order: Optional[str] = None
   ```
2. 類別判定分流器：
   - 美學/自費關鍵字或醫令碼（`Z0008`, `自費`, `皮秒`, `雷射`, `肉毒`, `玻尿酸`, `拉提`） $\to$ `category = 'special'`, `clinic_id = input.clinic_id`。
   - 一般疾病（`J` 開頭呼吸道, `K` 開頭消化道）且無自費處置標記 $\to$ `category = 'general'`, `clinic_id = None`。
3. 提示詞與萃取函式 `extract_faqs_from_soap(soap_data: SoapInput, llm_call: Optional[Callable[[str], str]] = None) -> list[ExtractedFaqItem]`：
   - 先透過 `scrub_clinical_input` 清洗各欄位。
   - 若提供 `llm_call` 則發送標準 JSON extraction prompt；若未提供或模擬測試環境，則依據結構化欄位規則進行啟發式提煉。
