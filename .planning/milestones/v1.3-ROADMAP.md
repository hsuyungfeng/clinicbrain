# Roadmap: clinicbrain — Taiwan Clinic Medical PageIndex RAG System

## Overview

從台灣健保開放資料出發，建立結構化資料庫與四段式 PageIndex 臨床推理樹，進而串接本地 LLM、多診所架構、API 同步與快取優先查詢。v1.3 拓展臨床端能力，接收外部系統（如 doctor-toolbox.com）推播之臨床聽寫與文字紀錄，透過確定性標記解析切分為標準 S/O/A/P 四段結構，自動萃取一般醫學特徵、症狀與居家照護建議，落實台灣個資法嚴格去識別化（身分證字號、電話、姓名遮蔽與 HMAC 偽名化衍生標籤），並支援院所醫師內部全文檢索。

## Phase Details

### Phase 14: 臨床語音與 SOAP 紀錄擷取
**Goal**: 透過官方 API 接收外部系統推播之臨床文字，安全解析切分為 S/O/A/P 結構並入庫至專屬 SQLite 資料表與 FTS5 虛擬表，提供院所醫師內部全文檢索與個資去識別化防護。
**Depends on**: Phase 5 (API 同步架構), Phase 6 (API 認證機制)
**Requirements**: SOAP-01, SOAP-02, SOAP-03, SOAP-04, SOAP-05
**Success Criteria**:
  1. 提供官方推播端點 `POST /api/v1/soap/records`，需 API Key 認證與診所身分檢核，以 `soap_writer.py` 增量 UPSERT 寫入 `soap_records`。
  2. 臨床文字自動解析切分 S/O/A/P：單字母標記（S/O/A/P）強制行首與標點、粗括號放寬切分、排除生命徵象 `P: 80` 衝突、無標記逐字稿安全退化為 subjective。
  3. 一般醫學特徵萃取（`extract_general_medical_insights`）：排除片語防禦（`r/o`、`rule out`、`疑似`、`鑑別診斷`）、後置否定容許寬容度比對、Assessment 為空時 conditions 保持 `[]` 留空降級。
  4. 台灣個資去識別化（`deid` 模組）：身分證（10 碼）、電話（09 開頭 10 碼）、中文姓名遮蔽；價格數字遞迴清洗為 `[請致電診所確認]`；患者 token 採 HMAC-SHA256 偽名化。
  5. 提供專屬查詢端點 `POST /api/v1/soap/search` 與 `GET /api/v1/soap/records/{external_id}`，強制唯讀連線 `PRAGMA query_only=ON` 與診所嚴格隔離。
  6. 遷移工具 `scripts/migrate_soap_schema.py` 支援 `--dry-run` 免確認旗標純記憶體 DDL 預覽。
  7. 全套回歸測試 69 項測試全數通過，正式資料庫 `clinic.db` SHA-256 恆定未受改動（`ad24426c`）。
